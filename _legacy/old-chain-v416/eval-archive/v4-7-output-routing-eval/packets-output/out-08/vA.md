# 坚果烘焙线：危害分析六列工作表怎么填、哪些危害要设预防控制

## 一、六列工作表怎么填

| 列 | 填什么 | 落地要点 |
|---|---|---|
| **1 步骤** | 原料接收 → 去壳/筛选 → 暂存 → 烘焙 → 冷却 → 调味/拌料 → 金属检测 → 包装 → 装箱入库 | 流程图必须**现场逐段核实**，含回掺、暂存、室温暴露、换班等易漏步骤；办公室画图直接进分析是已点名的失败模式 |
| **2 识别潜在危害** | 每一步列生物/化学/物理三类〔§ 117.130(b)〕，来源覆盖天然存在、无意引入、**为经济利益故意引入（EMA）** 三渠道 | 附录 1 的 X 标记只是**起点**，须过三问适用性检验（是否只覆盖子类部分产品／是否产地依赖／用途或状态是否改变危害）；表内空白≠无危害 |
| **3 是否需预防控制** | Yes / No | 分两层：评估层直接判 No；或判 Yes 但走〔§ 117.136(a)(1)–(5)〕五情形出口不实施 PC。两层混用会得出错误结论 |
| **4 判定理由** | 严重性 × 概率双维结论 +〔§ 117.130(c)(2)〕十因素留痕，书面 | 概率须按"**不存在任何预防控制时**"评估〔§ 117.130(c)(1)(i)〕，不得用"现有 CGMP 已在运行"压低；**判 No 与判 Yes 同等书面化**，空白的 No 在检查中等同没评估 |
| **5 预防控制是什么** | 控制类型 + 参数/关键限值 | 工艺控制关键限值须是参数的最大值、最小值或组合〔§ 117.135(c)(1)(i)(ii)〕 |
| **6 在哪一步控制** | 控制落点显式选位 | **发现点 ≠ 控制点**：可前移到供应商（走供应链程序），也可后移到金检/成品检测；一个控制可覆盖多危害（按最耐热/最难控的病原设计） |

法定骨架：危害分析必须**书面**且无论结论如何都成文〔§ 117.130(a)〕，基于"经验、疾病数据、科学报告及其他信息"〔§ 117.130(a)〕；FSP 含且仅含七部件〔§ 117.126(b)(1)–(7)〕，由 PCQI 编制或监督编制〔§ 117.180〕，整体是受 Subpart F 约束的记录〔§ 117.126(c)〕。新上线属重大变更，再分析须在**变更生效前或首批投产后 90 个日历日内**完成〔§ 117.170(c)〕，此后至少每 3 年整体再分析〔§ 117.170(a)〕。

## 二、坚果烘焙线要重点识别的危害

- **生物**：原料坚果/花生带**沙门氏菌**（低水分食品的经典危害，烘焙是致死步骤）；烘焙后冷却、调味、包装前若有高水分或室温暴露环节，须评估**金黄色葡萄球菌生长产毒**；成品若为 RTE 且包装前暴露于环境、包装后无致死处理，〔§ 117.130(c)(1)(ii)〕**强制**评估环境病原（李斯特菌/沙门氏菌）；低 a_w 下多数营养细胞不生长，但"不支持生长"只影响严重性评估、不等于不需控制，且专供医院/养老院等高危人群时不得降档；原料芽孢菌在复水或用于高水分下游产品时须重新评估。
- **化学**：**黄曲霉毒素等真菌毒素**（花生/树坚果原料，〔§ 117.80(b)(3)〕要求易感原料先符合 FDA 有毒有害物质规定，SIGNIFICANCE 标 `Potential health hazard` 的霉菌缺陷须联动化学危害分析）、农残、重金属；**过敏原**（花生/树坚果本身即主要食物过敏原，含交叉接触与标签错误两条失控路径）；清洁剂/润滑油/消毒剂残留、未批准添加剂；**EMA 掺假**〔§ 117.130(b)〕。注意〔§ 117.130(b)〕把"腐败分解 decomposition"列为法定化学危害，不能一律当质量缺陷踢出分析。
- **物理**：壳碎片、石块、金属屑、玻璃、硬塑料（筛选/磁选/金检控制）。

## 三、哪些必须设预防控制

判据：在"无预防控制"的反事实概率下〔§ 117.130(c)(1)(i)〕，经严重性×概率评估构成"已知或可合理预见、需预防控制"的危害〔§ 117.3〕〔§ 117.130(c)(1)〕，且不属于〔§ 117.136(a)(1)–(5)〕五情形出口的，必须设 PC。坚果线典型落点：

1. **沙门氏菌 → 工艺预防控制（烘焙致死）**〔§ 117.135(c)(1)〕：定温度×时间（及颗粒尺寸/料层厚度代理参数）关键限值，按目标菌做 log 削减验证（D/z 值、5D/6D），监控炉温与停留时间，配校准〔§ 117.160〕、偏差纠正〔§ 117.150〕、记录审查与验证。
2. **真菌毒素 → 原料/供应链控制**：按〔§ 117.80(b)(3)(4)〕做原料验收与供应商批准（Subpart G 供应链程序），COA/抽检/拒收/追溯成文；检测只能作补充手段，SAHCODH 类危害首次使用前＋每年现场审核，除非有书面替代认定。
3. **过敏原 → 过敏原预防控制**〔§ 117.135(c)(2)〕＋防交叉接触 CGMP〔§ 117.20(b)(2)〕（location / time / partition / air flow systems / dust control systems / enclosed systems 六类法定手段）：按过敏原谱递增排产、返工只许 like-into-like、清洁验证用**过敏原特异性检测**（ATP 阴性不能单独宣布合格）、标签"内容控制＋管理控制"双核对。注意〔§ 117.150(c)(1)〕的 correction 捷径只覆盖交叉接触，**不含标签错误**。
4. **环境病原 → 卫生预防控制**（若 RTE 暴露触发〔§ 117.130(c)(1)(ii)〕）：干区严格控水、湿区保持干燥、环境监测常规检 *Listeria* spp. 指示定殖、成品检 *L. monocytogenes*、人员手套与工服动线控制，与工艺控制**成对设计**。
5. **物理异物 → 视评估设筛选/金检控制**，落点通常后移到包装前（第 6 列），并配监控与失控产品隔离。

每个 Yes 至少配一个控制并显式选落点〔§ 117.135〕；若全部判 No，FSP 可只含书面危害分析（＋召回计划如适用），这是合法出口而非偷懒〔§ 117.126(b)〕〔§ 117.136〕。所有结论写成"默认态 + 触发条件 + 升格动作"三段式〔§ 117.170〕，FSP 与实施记录按〔§ 117.305〕含实际观测值、执行人签名、产品与批号、日期，按〔§ 117.315〕保存并按〔§ 117.320〕供官方调阅。
