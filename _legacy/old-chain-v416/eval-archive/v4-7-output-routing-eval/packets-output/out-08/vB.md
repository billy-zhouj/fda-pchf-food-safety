# 坚果烘焙线：危害分析六列工作表怎么填、哪些危害要设预防控制

> 前提：这是**烘焙线**（有附加加工），不是「仅去壳/脱壳/干燥/包装/存放」——后者依〔§ 117.5(k)(1)(v)〕连 Subpart B 都可豁免；一旦有烘焙，须完整适用 Part 117 Subparts B、C、G、F。坚果属 Big 9 主要食物过敏原，且生坚果是低水分食品沙门氏菌的经典载体。

## 一、六列工作表结构与填法

六列：**(1) 工艺步骤 → (2) 识别危害 → (3) 是否需要预防控制（Yes/No）→ (4) 判定理由 → (5) 预防控制是什么 → (6) 在哪一步控制**。

填写规则（每条都是检查点）：

1. **前期三件套先齐**：PCQI 编制或监督编制〔§ 117.126(c)〕、产品描述（配方、储运、预期用途、消费人群）、流程图。**流程图必须现场逐段核实**（含回掺、暂存、室温暴露、冷却、包装前暴露），办公室画图直接进分析是已点名的失败模式。
2. **第 2 列逐步骤穷举**：每一步覆盖生物/化学/物理三类〔§ 117.130(b)〕，来源覆盖原料/工艺/设施/人员；多组分按「Σ各原料危害 + 加工引入危害」分解。附录 1 的 X 标记只是**起点**，还要过三问适用性（是否只适用子类部分产品？是否产地依赖？我的用途/下游状态会不会改变危害？）——「表里没有」不能结案〔§ 117.130(a)〕。
3. **第 3、4 列判定**：严重性 × 概率，且概率必须在**「假设不存在任何预防控制」**的反事实条件下评估〔§ 117.130(c)(1)(i)〕——不许用「我们已经在烘焙」把概率压低再判 No。十类评估因素（配方、设施、原料、运输、加工、包装标签、储运、预期用途、卫生与员工健康、其他含时间/天气相关性）逐类留痕〔§ 117.130(c)(2)〕。**判 No 与判 Yes 承担同等书面举证义务**，空白的 No 等于没评估；危害分析无论结论如何都必须书面〔§ 117.130(a)〕。
4. **分清两层**：「评估层判 No」（该危害不构成需控危害）与「判 Yes 但走〔§ 117.136(a)(1)–(5)〕五情形出口不实施 PC」是两件事，混层会得出错误结论。
5. **第 5、6 列解耦**：**发现点 ≠ 控制点**。一个控制可覆盖多危害（按最耐热/最难的支配性病原设计）；控制位置选「最有效处」而非「发现处」——可前移到供应商（触发供应链程序），也可后移到成品检测。
6. **第 6 列结论写成状态机**：「默认态 + 触发条件 + 升格动作」三段式；FSP 至少每 3 年整体再分析〔§ 117.170(a)〕，变更/新危害信息/意外问题/控制无效触发局部再分析〔§ 117.170(b)〕。

## 三、哪些危害必须设预防控制（结论清单）

1. **沙门氏菌（低水分食品病原体）** → 工艺控制〔§ 117.135(c)(1)〕。关键限值须用**本产品**的热穿透/验证数据确立〔§ 117.160〕；低水分基质会显著抬高耐热性，文献极端值只作方向、不作设计依据，且禁止在温度档之间线性内插。
2. **过敏原（树坚果/花生）** → 过敏原控制〔§ 117.135(c)(2)〕，且**防交叉接触与标签两半都要有**（法定分界）。排产按过敏原谱递增、过敏原工序放最下游、返工只许 like-into-like；清洁验证用**过敏原特异性检测**（ATP 阴性不能单独宣布合格）；标签做内容控制 + 管理控制（接收/放行前/投产前至少一处对照规格核对）。注意〔§ 117.150(c)〕的 correction 捷径只覆盖交叉接触，**不含标签控制**——贴错标签必须走完整纠正措施。
3. **真菌毒素（黄曲霉毒素等）** → 化学危害，热处理不可逆，走供应链程序；若属「暴露后可能导致严重健康后果或死亡」档位，〔§ 117.430(b)(1)〕要求首次使用前 + 至少每年一次现场审核，除非依〔§ 117.430(b)(2)〕作出书面判定采用其他验证活动。
4. **包装后环境再污染（李斯特菌/沙门氏菌）** → 强制评估触发〔§ 117.130(c)(1)(ii)〕；坚果烘焙属低水分/干区，**干区防沙门氏菌靠严格控水**，湿洗后食品接触面须彻底干燥〔§ 117.35〕；设卫生控制并按需做环境监测〔§ 117.165(b)(3)〕。
5. **物理危害（石块、金属、玻璃、壳片）** → 按 § 117.130(c) 逐项评估，需要时设筛分/金检/去壳等控制。
6. **其他化学危害**：农药残留、重金属、润滑剂/清洁剂残留、未批准添加剂，以及**为经济利益故意引入（EMA）**（如低价坚果冒充高价品种）〔§ 117.130(b)〕——EMA 要查掺假模式库，不在附录 1 的 X 表里。
7. **质量缺陷不进危害分析**（虫害、毛发、异味等不致病不致伤，〔§ 117.3〕），但另有〔§ 117.110(a)〕`lowest level currently feasible` 与〔§ 117.110(b)〕掺混稀释禁令的持续义务；霉菌/霉变若涉及真菌毒素须转入化学危害分析。

## 四、每个 Yes 之后必须挂上的管理组件

监控〔§ 117.145〕、纠正/纠正措施〔§ 117.150〕、验证（validation 〔§ 117.160〕 / verification 〔§ 117.155、§ 117.165〕，监控与纠正记录 7 个工作日内由 PCQI 审查）、记录〔§ 117.190(a)〕、再分析〔§ 117.170〕。注意 validation 豁免是「四类列举 + PCQI 书面论证兜底」〔§ 117.160(c)〕，过敏原控制与卫生控制虽可免 validation，**管理组件全套仍在**〔§ 117.140〕。
