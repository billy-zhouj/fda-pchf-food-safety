# 海产品 HACCP 检查的六类分流与四类对象的特别要求

**一、检查类型分流（CP 7303.842 PART III）。** 检查判定链在「Table 1 产品风险 + Table 2 企业/进口商优先级」之后进入 PART III 的六类检查分流：**Processor（加工商）、Importer（进口商）、Vessels（加工船）、Foreign Establishments（境外加工商）、NSSP（认证双壳贝类企业）、EMA（经济动机掺假/食品欺诈）**，并在 PART III.C 做 HACCP Program Evaluations。共同前提：HACCP 检查应聚焦企业加工的**最高风险产品**且在**已知生产时**进行（L275）；Part 117 subparts C 与 G 不能替代 Part 123 的法定义务（L276）；重大缺陷记入 FDA 483，并另写叙述性 EIR（L285）。若同一加工商同时适用多个 compliance program（如罐装金枪鱼还牵涉 LACF/AF），原文要求按各适用程序分别覆盖（PART III.C / L273），时间有限时优先 03842H。

**二、四类对象各自的特别要求。**
- **加工船 Vessels**（L289）：FDA 承认在海上作业状态下检查多数加工船不现实，检查通常在**靠港、非作业时**进行；这是检查时点安排，不改变 Part 123 义务。
- **境外加工商 Foreign Establishments**（L299）：选点理由与国内厂相同——产品风险 + 合规史；只覆盖输美产品，且须取文档与照片证据。硬限制：境外加工商 HACCP 计划的其他缺陷**不得写进 FDA 483**，须取副本转 HFP（B7）；偏差未改正时可能被 DWPE（L1077，须 HFP OCE concurrence）。
- **NSSP 贝类企业**（PART III.E / L308）：认证软体贝类企业的检查**须由 shellfish standardized inspector 或 shellfish standardization officer 执行**，且须完成 NSSP 要求的课堂与现场标准化培训；作业用 ISSC Form 93-01(A)。贝类源头控制对应〔§ 123.28〕，NSSP Guide 与 Model Ordinance 正文本包转引未收。
- **进口商 Importer**（PART III.D / L311）：依〔§ 123.12〕，进口商须验证境外加工商符合 Seafood HACCP Regulation（21 CFR 123）、且产品食品安全危害被充分控制；在 MOU 或书面验证程序间二选一，落实 affirmative steps、产品规格，MOU 国家覆盖产品排除，每产品一份 FD 3502，必要时 for cause 索取境外 HACCP 文档。FSVP（CP 7303.878）是另一套法源，不得套用其「不取样 / PART IV 空白」口径。

**三、EMA 与通用纪律。** 一般食品欺诈监督活动须先取得 **HFP concurrence** 才可动用 Division 资源（FIELD REPORTING REQUIREMENTS / EMA / L75），HFP 可另行下发专项任务。

**四、效力层与误读防护（三层必须分开）。** 法规正文〔§ 123.xxx〕（CAP-22，`shall`）＞ FDA 技术指南（CAP-23，Seafood Hazards Guide 第 4 版 Ch.x 的 `should`）＞ CP 7303.842 检查程序作业层（CAP-24，给 field staff、不创设企业义务）。既不能把 CP 的分流动作、优先级表、取样/上报口径写成企业义务，也不能因 CP 非强制把〔§ 123.6〕〔§ 123.12〕等 `shall` 义务稀释成可选。本件内容按「CP 7303.842 PART x / Table x / ATTACHMENT A #x / Lxxx」定位，不与〔§ 123.xxx〕、指南 Ch.x 或 CP 7303.050/070/878 混引；全包自 v4.11 起**十六类来源不可混引**。CPG、BAM、NSSP Guide、Import Alert、21 CFR part 120 / part 1 subpart L 等未收正文一律标「转引未收」。本答复不代填 3501/3502、不预测检查分类、不出合规结论。
