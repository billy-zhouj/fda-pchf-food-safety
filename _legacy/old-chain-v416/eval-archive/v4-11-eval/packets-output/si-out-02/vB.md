# 程序已合并，但 PAC 码表没有合并

**结论：合并了，但合并的是「程序」而不是「码表」；进口与国产样品并不报同一个 PAC 码。**

**一、合并关系：已合并为单一程序。** 首页 NOTE 与 CP 7303.842 PART I / L142 原文写明：`The current Seafood Processor and Imported Seafood Inspection Program, CP 7303.842, is a combination of the previous compliance programs, the Seafood Processor Inspection Program (CP 7303.842) and the Imported Seafood Inspection Program (CP 7303.844).` 因此现行只有一份 CP 7303.842，CP 7303.844 不再是独立现行程序；进口商与境外加工商的调查活动也由 HFP 统一整合（PART I / L144）。

**二、合并的是程序，不是码表——进口和国产不报同一个 PAC。** 首页 NOTE 明确 `PAC codes for sampling and analysis will still reflect whether the product is imported or domestic`。取样／分析 PAC 仍按进口／国产分列：进口用 `03844x`、国产用 `03842x`。例如 CP 7303.842 PART IV.C / L484 规定，感官分析结果进 FACTS 用 PAF「DEC」+ 国产 `03842C` / 进口 `03844C`；组胺（histamine）与 indole 用国产 `03842A` / 进口 `03844A`。检查报告另有一套报告 PAC（03842 / 03842H / 03844H / 03040），与分析 PAC 不可混为一谈。所以「合并后进口和国产样品都报同一个 PAC」是典型误读。

**三、两个最容易踩的码表坑。** ① `03842H` 同名不同义：在取样／分析表里它是 `HACCP Verification`（验证 HACCP 计划关键限值的充分性），且进口列注明 `Not applicable`（L18）；在检查报告表里它却是 `Processor HACCP Inspection` 的报告 PAC（L31）。② documentary samples：CP 7303.842 PART III.F / Documentary Samples / L339 规定，支持州际贸易等的 documentary samples **只报 03842**，不得用以 `H` 结尾、保留给 HACCP verification samples 的 PAC，也不计入 Division Workplan 义务。海产品食品欺诈 PAC `21842` 另行保留（PART IV.G / L937）。

**四、效力层与误读防护（三层必须分开）。** 法规正文〔§ 123.xxx〕（CAP-22，`shall` 法定义务）＞ FDA 技术指南（CAP-23，Seafood Hazards Guide 第 4 版 Ch.x 的 `should` 建议层）＞ CP 7303.842 检查程序作业层（CAP-24，给 field staff、不创设企业义务）。PAC/PAF 是检查员向 FACTS／CMS 上报与统计的作业口径，既不能把 CP 的 PAC、Table 1/2 优先级、PART IV 触发值写成企业义务或产品放行标准，也不能因 CP 非强制把 Part 123 的 `shall` 义务稀释成可选。本件内容按「CP 7303.842 PART x / Table x / ATTACHMENT A #x / Lxxx」定位，不与〔§ 123.xxx〕、指南 Ch.x 或 CP 7303.050/070/878 各自的 PART 混引；全包自 v4.11 起**十六类来源不可混引**。CPG、BAM、NSSP Guide、Import Alert（16-74/16-20/99-41 等）、21 CFR part 120 / part 1 subpart L、FDA 3501/3502 表单全文等未收正文一律标「转引未收」，不从 CP 反推。本答复不代填表单、不预测检查分类。

**五、不确定处。** 本包未逐行收录完整 PAC 清单，某一具体分析项目的后缀字母须回 CP 7303.842 PART IV 与 PAC 表原文核对；但「进口 03844x／国产 03842x 分列、程序合并≠码表合并」是材料逐字给出的硬口径。
