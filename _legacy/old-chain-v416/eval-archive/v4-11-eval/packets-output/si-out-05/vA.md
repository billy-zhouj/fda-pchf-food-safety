# 关于国内厂常规 HACCP 检查是否必取官方样品、取样量能否只按 Table A-1 的答复

**结论：不是每次都要取官方样品送检；取样量也不能只照抄 ATTACHMENT A 的 Table A-1。**

**一、常规检查的核心不是取样。** 一次例行 HACCP 检查主要是文件与现场审查：危害分析是否识别出「有合理可能发生」的显著危害、HACCP 计划的 CCP／关键限值／监控／纠偏／验证／记录是否完整且与实际一致、卫生监控与 CGMP、培训、验证与复核记录，以及企业是否按计划运行。官方样品属于**选择性、有因或按任务**的动作：通常在发现可疑产品或记录异常、针对特定危害（组胺、致病菌、腐败分解、净重、物种鉴别、亚硫酸盐／过敏原等）、投诉或进口拒绝后跟进、或按专门抽样任务执行时才会采集，而不是「每厂必取」。

**二、官方样品还有程序性成本。** 官方样品（official sample）须由授权人员按 IOM 采集、建立样品记录、依法应企业请求给予样品 portion（FD&C Act §702(b)）、封样、保持冷链并送 FDA 实验室。这些手续和成本也决定了它不会被例行化。另有一种「文件样品」（documentary sample）只收集单据、不含实物，更不送实验室。

**三、Table A-1 不够用。** 即便附件 A 的 A-1 表给出了某类分析的取样单元数，实际取样量还取决于：分析项目与检测方法所需样品量、是否做混合或分样、批量大小与抽样方案（如微生物学的属性抽样 n／c／m／M 方案）、是官方样品还是调查样品、以及具体抽样任务／工作分配指令。单独一张表无法覆盖「取几份、每份多少、如何分样与留样」，也不能替代 IOM 采样程序与实验室对样品量的要求。

**四、如实说明的不确定处。** 我没有读过这份 2025 版的附件 A，不能确认 Table A-1 的确切内容，也不确定它是否专门针对取样量、还是针对取样情形或优先级；更不掌握本版对「何时必须取样」的判断条件。因此不替你断言「照 A-1 就行」。

**五、建议的判断顺序。** 先看程序规定的取样触发条件 → 确认是否属官方样品及对应任务 → 查 IOM 与分析方法的样品量要求 → 再参考附件表格确定单元数 → 完整填写样品记录与chain of custody。

**一句话答复：** 常规检查以记录与现场审查为主，取样是有因／按任务的；取样量需综合方法、批量、抽样方案与任务指令，不能只看一张表。
