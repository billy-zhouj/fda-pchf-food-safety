# 国产官方样品不是「每次必取」，ATTACHMENT A 的样品量也不能照搬

**结论：两个判断都是否定的——国产官方样品仅「有因」才采，不是每次必取；ATTACHMENT A 的 Table A-1 样品量也不能直接「就行了吗」。**

**一、国内厂常规 HACCP 检查不是每次都取官方样品。** 原文（CP 7303.842 PART III.F / Domestic For Cause Sampling / L327）：`Domestic official samples are to be collected "for cause" only.` 即国产官方样品**仅限 for cause（有因）**采集，不常规靠取样支持 HACCP 违规。更反直觉的是：当控制明显不足时，检查员**不取样**，而是在 FDA 483 上说明控制缺失、在叙述性 EIR 中描述现场条件；确需取样须先联系 HFP（B8）。本程序把取样分三类：国产 for cause only、进口监督取样（OII Workplan 定数量、既往缺陷条目优先，L330）、documentary samples（只报 03842、不计入 Workplan，L339）。所以「常规检查每次都送检」是错的，「不取样」本身也是检查结论之一。

**二、Table A-1 的样品量有严格适用域。** 表 A-1 的 subs 数多处明说 `only for surveillance and audit samples`（CP 7303.842 ATTACHMENT A #3 / L1210，另见 PART IV L465、L546、L565），**不得**用于 reconditioning 返工验证（#3）、**不得**用于 DWPE 放行（#4）、**不得**用于 Domestic HACCP Verification（#5，须先咨询 HFP）；702(b) duplicate 部分**不含在表列 subs 内**（#6）；此外还有 Filth for cause、CFP 仅疾病响应、RTE 才做 Listeria 等硬限制。ATTACHMENT A / General Information / L1218 还要求 subs 随机抽取以覆盖批次，批次含多产品码或日期码时须覆盖多个 codes。这些数字是检查员取证口径：不能写成法规限值、产品放行标准或 BAM/AOAC 方法全文。净重过镀冰 48 subs（PART IV.G / L942）、AOAC 963.18、CPG Sec. 562.300 等判据与方法正文转引未收。

**三、正确做法。** 先判这次检查属哪一类取样：多数国内常规 HACCP 检查不取样；若属 for cause 且确为 surveillance／audit，才参照 Table A-1 的 subs 数，并按具体项目（#3／#4／#5）走各自规则；进口监督取样数量由 OII Workplan 定而非 Table A-1。涉及通用产品样品 subs 数、每 sub 克数、环境拭子 Zone 1–3 的，属 CP 7303.050（inspection-sampling 卡），不得与本 CP 的 ATTACHMENT A 混用；CP 7303.050 的 subs 数是 FDA 取证量，**不是企业批放行标准**。

**四、效力层与误读防护（三层必须分开）。** 法规正文〔§ 123.xxx〕（CAP-22，`shall`，如〔§ 123.6〕危害分析与书面 HACCP 计划、〔§ 123.8〕验证）＞ FDA 技术指南（CAP-23，Seafood Hazards Guide 第 4 版 Ch.x 的 `should`）＞ CP 7303.842 检查程序作业层（CAP-24，给 field staff、不创设企业义务）。既不能把「for cause only」「ATTACHMENT A subs 数」写成企业取样义务或放行标准，也不能因 CP 非强制把 Part 123 的 `shall` 义务稀释成可选。本件按「CP 7303.842 PART x / Table x / ATTACHMENT A #x / Lxxx」定位，不与〔§ 123.xxx〕、指南 Ch.x 或 CP 7303.050 混引；全包自 v4.11 起**十六类来源不可混引**。CPG、BAM、NSSP Guide、Import Alert、21 CFR part 120、IOM Chapter 4 的 702(b) 分割留样规则等未收正文一律标「转引未收」，不从 CP 反推、不代填表单。
