## I — 自述

我是一张**进口轨道分流卡**，不是 FSVP 法规卡。用户拿着一封 FDA 的 FSVP 检查通知、一份 483a、一张 Import Alert 99-41 截图，或问「我们已经做了 Part 117 供应链验证，还要不要做 FSVP」时，我做的第一件事不是报条款号，而是问三件事：**谁是 FSVPI（§1.500 定义）、这个主体是不是 receiving facility 因而可走 deemed-compliance、这次动作是 FSVP 检查还是 PCHF 检查 / 7303.050 抽样 / 7303.070 罐头检查？** 顺序错了，后面全错——把 FSVP 与 Part 117 Subpart G 当成同一套义务会凭空造出或漏掉一整套记录；把 CP 7303.878 的检查动作写成企业法定义务会凭空造出法条。

我能给的是**检查员视角的清单与执法阶梯**：FSVP 是否按食品建立、书面危害分析与供应商批准评价、供应商验证活动记录、§1.509 每一 entry line 的 UFI/DUNS、modified requirements 适用判定与资格证明、483a 观察分级、NAI/VAI/OAI、Warning Letter → Import Alert 99-41 Red List → §801(a)(3) 拒绝入境。我也能给出**关键反直觉口径**：FSVP 检查不取样；deemed compliance 不免除 §1.509；§1.507 disclosure 不能替代 §801(b)/§1.95 整改资料；未上 Red List 仍可继续进口；首次违法不默认优先执法。

我明确拒绝三件事：把 CP 7303.878 的检查动作写成企业法定义务；**从 CP 反推 21 CFR part 1 subpart L 条文**（正文本包未收，一律「转引未收」）；以及把 **Import Alert 99-41** 与 CP 7303.070 的 **99-37 / 99-38**（LACF/AF 备案与过程控制）混为一谈。企业侧「怎么选验证活动、SAHCODH 年审、检测能否当唯一手段」请回 `supply-chain-verification`；法规条文级的 Part 117 义务请回〔§ 117.xxx〕；Part 113/114 条文请回 CAP-20。

## A1 — 书中案例

1. **「我们是进口商也是加工厂，已经按 Part 117 做了供应链验证」**：PART II.3.A 原文给了 deemed-compliance 通道，但括号里 `except they must comply with section 1.509` 把入境标识义务单独留下。CPGM 7303.040 PART III 也有同义表述。常见错误是「既然 deemed in compliance，全套 FSVP 都不用做」，以及「既然 deemed，UFI/DUNS 也不用报」——后者与原文相反。
2. **纯贸易公司被开 FSVP 483a**：PART II.3.A 明写 `An importer that is not a receiving facility ... must comply with the FSVP requirements`。只做进口、不从事制造加工的主体没有 supply-chain-program 可借用，必须自己有 FSVP；仅受 Subpart B CGMP 或 §117.206 modified requirements 约束的仓储设施也可能单独接受 FSVP 检查。
3. **VSI 拿不出记录却说「我们适用 modified requirements」**：PART III.1.A.ii 要求检查员在 EIR 里**独立写明**适用哪套要求，不受企业声明约束；若连资格证明在内的任何 modified requirement 记录都没有，可引用「No FSVP」records under §1.502(a)；反过来，只要有**任一** §1.512 记录就应按 modified requirements 检查并只针对缺失项开观察。这是「全有全无」判断的反例。
4. **FSVP 检查却按 7303.050 准备样品**：PART III.1.C `Samples will not be collected as part of an FSVP inspection.` 与 PART IV 四节 `Intentionally Left Blank`，说明 FSVP 检查是**记录审评**型；把 CP 7303.050 的样品量、环境拭子、PAF 代码套过来是典型串轨。
5. **进口商想用 §1.507 disclosure 顶替整改资料**：PART V.1 Note 明写 FDA 不把该披露要求当作 §801(b) / §1.95 reconditioning proposal 所需信息的替代（例如对污染食品加 kill step）。这是「有披露声明就能放行」这一推论的原文反证。
6. **收到 Warning Letter 后以为全线停运**：PART V.3.C.i 的 Red List 是按「具体食品 + 具体境外供应商」组合或全部食品列入；未列入的组合在不受其他 Import Alert 约束时仍可进口。移除须按 99-41 指示向原发函 Division 提交证据、经 CMS 建议并咨询 Center，且应**先申请移除再进口**。
7. **把 99-41 当成 99-37**：CP 7303.070 PART V.2 的 99-37/99-38 针对 LACF/AF 的 scheduled process 备案与过程控制，且明写「不得仅因未注册/未备案建议 DWPE」；99-41 针对 FSVP 不合规的进口商。两者的触发条件、列名对象（企业/产品组合 vs FSVPI/食品/供应商组合）与法律 hook 都不同。

## A2 — 未来触发

1. 「我们做进口，还要不要建 FSVP？」→ 先按 §1.500 判 FSVPI 身份，再看是否是 receiving facility 且符合 part 117/507 供应链要求可 deemed compliance；**§1.509 不免**。
2. 「FSVP 和 Part 117 Subpart G 供应链程序是不是一回事？」→ 两套法源、两类主体，`supply-chain-verification` 管企业侧验证决策，本卡管进口商义务与检查分流。
3. 「没有美国货主/收货人时谁是进口商？」→ §1.500 第二款：签署同意书的美国代理/代表。
4. 「UFI 是什么、什么时候报？」→ §1.509：每一 entry line 报关时电子提供名称、邮箱、UFI；FDA 认可的是 **DUNS**。
5. 「哪些进口食品豁免 FSVP？」→ §1.501(b)–(h) 八类（part 120/123 合规的果汁与水产及其原料、研究评估用、个人消费、酒精饮料相关、转运、进口加工后复出口、美国出口退回、USDA 管辖的肉禽蛋）。
6. 「standard 与 modified requirements 怎么分？」→ §1.502/503/504/505/506/508/509/510 vs §1.507/511/512/513；满足 modified 条件者**可以选择**走 standard。
7. 「进口膳食补充剂是不是自动适用 §1.511？」→ 须先排除 1.511(a)/(b)（进口商或其客户为制造商），否则考虑转 OP13；仅作成分且双方都不制造时不适用 modified。
8. 「我们是极小进口商 VSI，没记录会怎样？」→ PART III.1.A.ii：无任何 modified requirement 记录（含资格证明）可引「No FSVP」under §1.502(a)；检查员须自行在 EIR 写明适用要求。
9. 「FDA 要做 FSVP 检查，我们要备样吗？」→ **不取样**（PART III.1.C）、PART IV 全空；备的是危害分析、供应商批准评价、验证活动、纠正措施、§1.509 记录。
10. 「检查可以是远程的吗？」→ PART III.1.A `on-site or remote`；RRA 的法定地位另见 CAP-19 的 `RRAs are not considered inspections` 与 IOM Ch.5（本包已收）。
11. 「我们收到 Form FDA 483a 了，最严重的是哪些？」→ PART V.1.A 六类重大观察（未建/未维护/未遵循 FSVP、无书面危害分析、无供应商批准评价、无验证活动、未履行 modified 活动、**书面索取后未及时提供记录**）。
12. 「首次检查有缺陷就一定会被警告信吗？」→ PART V.1.C：首次违法**仅在已知食品安全风险时才优先执法**；还要看违法史、SAHCODHA 风险、进口量、偏差范围、自愿合规与渐进改善、是否换个商号继续进口。
13. 「NAI / VAI / OAI 怎么定？」→ PART V.1.D 按观察对公共卫生的重要程度与企业响应分类；OAI 执法建议经 CMS 上报。
14. 「什么情况下货物会被拒绝入境？」→ PART V.2：§805 不合规 → §801(a)(3) / §1.514(a) 拒绝入境，附官方指控措辞；无 FSVP 进口另构成 §301(zz) / §1.514(b) 禁止行为。
15. 「Division 能直接发 FSVP 警告信吗？」→ PART V.3：direct reference authority 仅限 HFP Enforcement Bulletin #13 描述的有限情形；否则须经 CMS 送 HFP OCE OE Imports Enforcement Branch（动物食品 CVM OSC DFC）并取得分类一致。
16. 「上了 Import Alert 99-41 是不是所有货都进不来？」→ 按「食品 + 供应商」组合或全部食品列入 Red List；未列组合在不受其他 Alert 约束时仍可进口；移除流程按 99-41 指示，先申请再进口。
17. 「99-41 和 99-37/99-38 有什么区别？」→ 前者 FSVP 不合规进口商，后者 LACF/AF 备案与过程控制；不得混引。
18. 「州政府/地方监管部门会来做 FSVP 检查吗？」→ PART II.5.B：`Currently, FDA is not assigning FSVP inspections to State and Local counterparts.`
19. 「我们有 SRA，能不能走 §1.513？」→ 仅限「不再进一步加工/制造且在 SRA 范围内」的人类食品；须核实供应商所在国体系被 FDA 正式认可/等效且食品在范围内。
20. 「CP 7303.878 是不是 2025 年新规？」→ 版本陷阱：2023-09-27 版程序 / 2025-08-28 更正（仅 POC 与机构名称）。
21. 「21 CFR 1.505 原文怎么要求的 / Import Alert 99-41 全文 / FSVP Guidance Q&A G.8 / IP guidance tabs 写什么？」→ 转引未收，明确告知超出本包，不要硬套。
22. 「CP 7303.819 是不是废止了？」→ 更正为「2006 FY06-08 旧程序、已过 completion date、非现行；7303.878 把一般进口作业内容交由其更新版承接」，本包仍未收。

## E — 执行要点

**Step 1 — 先判主体与轨道，再谈义务（顺序不可颠倒）**

| 观察 | 轨道 | 本包可读到的 |
|---|---|---|
| 美国货主/收货人（或签署同意书的美国代理）进口食品 | **FSVPI / CP 7303.878** | 本卡 + 〔§ 117.xxx〕交叉 |
| 进口商同时是 manufacturer/processor 且符合 part 117/507 供应链要求 | **deemed compliance**（不免 §1.509） | 本卡 + `supply-chain-verification` |
| 不是 receiving facility 的纯贸易进口商、仅受 Subpart B 的仓储设施 | **完整 FSVP，单独接受 FSVP 检查** | 本卡 PART II.3.A |
| 果汁 / 水产且供应商符合 part 120 / 123 | **§1.501(b) 豁免** | 本卡（part 120 见 CAP-26；part 123 见 CAP-22） |
| 低酸罐头 / 酸化食品进口 | 7303.878 与 7303.070 的接口（§1.502(a)-(b)） | 本卡 + CAP-19 / CAP-20 |
| 农产品 / 膳食补充剂 / 动物食品 | 7303.080 / 7321.008 / 7371.000 与 03878P / 03878D / 71878 | 本卡（仅分流，各 program 正文未收） |
| 检查员要取样或送实验室 | **不是 FSVP 检查**（PART III.1.C / PART IV 全空） | 转 `inspection-sampling`（CP 7303.050） |

**Step 2 — 把「法定义务 / 检查动作 / 转引未收」三层切开**

- **法定义务层**：FD&C Act §805、§801(a)(3)、§301(zz) 与 21 CFR part 1 subpart L（§§1.500–1.514）——**法规正文本包未收**，只能写「转引未收」，不得从 CP 反推条文；CP PART I.1 自己声明 `Below is a summary of the FSVP requirements`。
- **检查动作层**：CP 7303.878 PART x 的取证清单、483a 观察分级、CAR/eNSpect、执法建议路由——**不创设企业义务**。
- **Part 117 层**：〔§ 117.135〕起的 Subpart G 供应链程序是法条，可用〔§ 117.xxx〕引用；与 FSVP 的 deemed-compliance 接口写「CP 7303.878 PART II.3.A」而不是写成 Part 117 条文。
- ⚠ 不要把 §117.5(d)（part 113 活动的 Subparts C/G 豁免）套到 FSVP 上——那是 LACF 接口，见 CAP-19 / CAP-20。

**Step 3 — 备齐检查员会索取的 FSVP 记录**

| 组 | 内容 | 出处 |
|---|---|---|
| FSVP 本体 | 按**每一种食品**建立的 FSVP、书面危害分析（或对他方危害分析的审阅记录）、FSVP 变更与再评价记录 | PART I.1 / III.1.A / V.1.A |
| 供应商 | 批准评价、书面批准、仅从已批准供应商进口的书面程序、验证活动记录与结论 | PART III.1.A / V.1.A |

| modified | 适用判定与资格证明（VSI 销售额/进口额数据、小供应商、SRA 范围、§1.511(c) 适用性、§1.507 disclosure 与书面保证） | PART III.1.A.ii |
| 纠正措施 | 偏差与纠正、现场纠正及计划纠正的时间表、483a 回复 | PART III.1.A / V.1.B |
| 响应能力 | FDA 书面索取后**及时**以电子或其他方式提供记录的能力与留痕 | PART V.1.A |

**Step 4 — 执法阶梯只按原文取用**

| 阶段 | 触发 | 出处 |

| 观察 | Form FDA 483a / FSVP Observations；重大 / 较重大 / 较轻三档 | PART V.1.A |

**Step 5 — 数值与编号只按用途取用**

## B — 边界

**B1 — 21 CFR part 1, subpart L（§§ 1.500–1.514）法规正文本包未收。** CP PART I.1 自己声明只是 summary；凡「§1.5xx 原文怎么规定」一律标「转引未收」，不得从检查员作业指导反推条文，也不得把 CP 的检查动作写成企业法定义务。CP 7303.878 是 **FDA 内部作业指导**（`provides instruction to field staff`），不是法规、不是 Guidance for Industry。

**B2 — 不要把 FSVP 与 Part 117 Subpart G 供应链程序合并叙述。** 主体不同（FSVPI vs receiving facility）、法源不同（FD&C Act §805 / 21 CFR part 1 subpart L vs FD&C Act §418 / 21 CFR part 117 Subpart G）。deemed compliance 的原文带 `except they must comply with section 1.509`；「不是 receiving facility」的进口商没有该通道。

**B3 — FSVP 检查不取样。** PART III.1.C 与 PART IV 四节 `Intentionally Left Blank`；CP 7303.050 的样品量、环境拭子、WGS、PAF 代码不得套到 FSVP 检查。

**B4 — Import Alert 99-41 不是 99-37 / 99-38。** 后者属 CP 7303.070 的 LACF/AF 备案与过程控制轨道，且该卡另有「不得仅因未注册/未备案建议 DWPE」的反直觉限制；99-41 的列名对象是 FSVPI / 食品 / 境外供应商组合，触发条件是 FSVP 不合规且 WL 后未纠正。

**B5 — 未上 Red List ≠ 自动禁运；上了 Red List ≠ 全部食品停运。** PART V.3.C.i 明写未列名组合仍可进口（前提是不受其他掺假/误标 Alert 约束），列名可按组合或全部食品。移除须按 99-41 指示提交证据并**先于**再次进口。

**B6 — §1.507 disclosure 不是万能挡箭牌。** PART V.1 Note：不能替代 §801(b) / §1.95 reconditioning proposal 所需信息；详见 FSVP Guidance Q&A G.8（本包未收）。

**B7 — 首次违法不默认优先执法，direct reference 不是普遍授权。** PART V.1.C 与 PART V.3 的裁量因素与 Center concurrence 要求必须一起给，不能只报「会发警告信 / 会上 Alert」。

**B8 — modified requirements 不是「少做一套」的同义词。** 满足 §1.512/1.513 等条件者可**选择**走 standard；检查员须独立在 EIR 写明适用要求；无任何 modified 记录（含资格证明）可引「No FSVP」under §1.502(a)。§1.511(c) 还须先排除 (a)/(b) 并考虑转 OP13。

**B9 — 版本口径锁定 2023-09-27 版 / 2025-08-28 更正。** 首页 `Date of Issuance: 08/28/2025` 不是新程序年份；Change History 的 2025 条目只改 POC 与机构名称缩写。不得写成「2025 版 7303.878」或套用 CPGM 7303.040 的 Transmittal 形态。

**B10 — CP 7303.819 表述更正。** 它是 2006 年 FY06/07/08 旧程序（COMPLETION DATE 9/30/08、非现行），不是「法规意义上的废止」；CP 7303.878 的 2023 Update 说一般进口作业内容交由其更新版承接。本包仍未收 7303.819 正文，也不收 7303.080 / 7303.803A / 7321.008 / 7371.000 等 program 全文；**7303.842 自 v4.11 起已收**（第十六来源，CAP-24 `seafood-inspection-program`），但它仍是检查程序作业层，不是 FSVP 法规正文，也不改变本卡的 FSVP 判定链。

**B11 — 十四类来源不可混引**：21 CFR Part 117 法规正文 / FDA PCHF 行业指南 / L.mono Draft Guidance / SECG / 过敏原 Ed.5 / Food Defect Levels Handbook / CPGM 7303.040 / CP 7303.050 / IOM 2026 Ch.5 / CP 7303.070 / 21 CFR Part 113 法规正文 / 21 CFR Part 114 法规正文 / CP 7303.878 / **FDA《Fish and Fishery Products Hazards and Controls Guidance》第 4 版 June 2022（第十五来源，CAP-23）**。检查员作业指导一律不创设企业义务；shall/must 的法定义务只回法规正文。

**B12 — 超出 28 张能力卡路由范围时，明确告知超出本包覆盖，不要硬套。** FSVP 法规条文、Import Alert 99-41 全文、FSVP Guidance for Industry、FSVP Implementation Work Instructions 与 IP guidance tabs、HFP Enforcement Bulletin #13/#6、RPM 4-1-8、SOP-001642、21 CFR part 111 / 112 / 120 / 507 正文（part 123 已收，见 CAP-22）、FSVP 检查结论预测与具体案件法律意见，均不在本包内；企业侧供应商验证活动设计转 `supply-chain-verification`，检查员表单与证据链转 `investigator-authority-procedure`，迎检准备转 `inspection-readiness`。
