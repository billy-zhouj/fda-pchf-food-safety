## 1. 这是什么性质的文件

Part 172 不是「原则型法规」，是**逐物质许可清单（per-substance positive list）**。它对约 150 种物质逐个回答四件事：

1. **这个物质是什么**（identity：化学名、CAS 号、制备方式、组成范围）
2. **纯度要达到什么规格**（specifications：assay 下限、杂质上限、重金属上限；或整体「incorporated by reference」到 Food Chemicals Codex）
3. **能用在哪里、用多少**（use / limitations：特定食品 + ppm 上限，或仅 GMP 约束）
4. **安全使用所需的标签与使用说明**（"To assure safe use of the additive..."）

**这决定了它的能力形态**：不是「教你判断危害」，而是「给你一张可核对的许可表 + 一套读表规则」。误用的主要形态不是“理解错原则”，而是**引错条款、把 GMP 条款当成有 ppm 上限、把某物质在某食品的许可推广到其他食品、把 IBR 规格当成包内可查数值**。

## 3. 关键发现：Part 172 有一套高度重复的条款语法

这是本件最可复用的方法层发现——**154 条里有 66% 含量化限制、44% 含身份定义、40% 含纯度规格、27% 含 IBR 引用**。条款几乎都按同一模板展开，因此可以用**一条判定链覆盖全部条款**，而不需要逐条记忆。

### 3.1 限制条件的五种形态（实测分布）

| 形态 | 条款数 | 判定含义 | 举例 |
|---|---|---|---|
| ① **ppm / 百分比数值上限** | **80** | 有明确剂量红线，须对成品检测 | §172.110 BHA 50 ppm、§172.177 亚硝酸盐 100–200 ppm |
| ② **仅受 GMP 约束（无具体数值）** | **34** | 只有「不超过实现效果所需量」，**无固定数字** | §172.235 Morpholine、§172.330 泛酸钙 |
| ③ **仅限特定食品/用途** | **8** | 用量靠 GMP，但**食品范围是封闭清单** | §172.167 银离子过氧化氢（仅特定用途） |
| ④ **功能/用途限定** | **11** | 只能以某功能身份使用（如仅作营养强化） | §172.379/380 维生素 D2/D3 |
| ⑤ **无明显限制语** | **21** | 多为长尾物质，只用 GMP 总则兜底 | §172.255 Polyacrylamide |

> ⚠ **最高频误读**：把 ②③④⑤ 当成「有 ppm 上限」，或把 ① 的数值当成「所有食品通用」。**有条款 ≠ 有剂量上限；有 ppm ≠ 全食品适用。**

### 3.2 四段式条款模板

```
(a) Identity        化学身份 / CAS / 制备方式 / 组成范围
(b) Specifications  assay 区间、杂质上限、重金属上限，或 IBR 到 FCC / 厂商方法
(c) Use            可用于哪些食品、以什么功能、上限多少（上表五形态之一）
(d) To assure safe use   标签须载明名称/浓度、须给足使用说明以保证成品合规
```

**IBR（incorporated by reference）是本件的关键陷阱**：43 条（27%）把纯度规格整体引用到外部文件（Food Chemicals Codex 7th ed.、厂商分析方法、AOAC）。**这些规格不在本 PDF 内、也不在本技能包内**，只可引「须符合某文件某页」，绝不可转述具体数值。

## 4. 与 PCHF 技能包（v4.18，30 卡）的接口

### 4.1 本次真正补齐的缺口

现有包对「添加剂」的表述全部在**危害/控制层**：化学危害识别（CAP-06）、CGMP（CAP-14）、工艺控制（CAP-03）、标签内容（CAP-30 Part 101）。**但从未收录「某物质是否被许可、上限多少」这一层**。用户问「我们这个防腐剂能不能用在焙烤食品里、上限多少」时，包里只能讲控制原则，给不出许可依据。

### 4.2 三条必须写死的分工

1. **Part 172（许可与限量）↔ Part 101（标签内容）**：某添加剂被许可，不代表配料表可以怎样写；配料表写法回 CAP-30〔§ 101.4〕。反过来，标签合规不代表添加剂用得合法。
2. **Part 172（许可）↔ Part 117（过程控制）**：§172.5(b) 明文——**「有安全使用条件的法规，不得解释为免除该物质遵守本法其他任何规定」**。即：用了被许可的添加剂，仍要做危害分析、仍要符合 CGMP、仍要控制过敏原。
3. **Part 172（直接添加剂）↔ Part 175–178（间接添加剂，未收）/ Part 170–171（请愿程序，未收）**：食品接触材料、包装迁移物不在本件；新增添加剂须走 petition（Part 171）或 GRAS 认定，也不在本件。

### 4.3 与既有卡的具体分工点

- **§172.785 李斯特菌噬菌体**（Subpart H）是**生物类抗菌剂**：它是「许可的添加剂」，不是「环境监测程序」；RTE 环境病原控制仍回 CAP-04，两者不可互替。
- **§172.177 烟熏鲢亚硝酸盐**：给出盐 ≥3.5%、亚硝酸盐 100–200 ppm、160 °F/30 min、50 °F/3 h + 38 °F/12 h 的完整四重控制——这是**法规正文层的工艺参数**，与 CAP-26 果汁 5-log、CAP-03 工艺验证是不同法源，但可作为同类「多栅栏」结构的法条范例。
- **§172.110 BHA / §172.115 BHT / §172.185 TBHQ**：抗氧化剂限量表，与 CAP-06 化学危害的「添加剂过量」判定直接咬合。
- **§172.804 阿斯巴甜 / §172.831 三氯蔗糖 / §172.829 新橙皮苷二氢查尔酮(Neotame)**：甜味剂，若产品声称「无糖/低糖」，则**声称判定回 CAP-30 V03〔§ 101.60〕**，许可判定在本卡，两套并行。

## 5. 批判：这份法规不告诉你什么（四条硬边界）

1. **不告诉你某物质「安全」**——它只说明「在所列条件下使用不被视为不安全」。§172.5(c) 甚至明文：营养物质的允许使用条款**不构成**该物质作为膳食补充有用或必需的认定。
2. **不给企业内控规格**——ppm 上限是**法规红线**（成品不得超），不是内控目标值，更不是「推荐添加量」。内控必须更严并留检测不确定度余量。
3. **不覆盖全部添加剂**——GRAS 物质、Prior-Sanctioned 物质、临时许可（Part 180）、间接添加剂（Part 175–178）、色素（Part 73/74/82）都不在 Part 172。**「Part 172 查不到」不等于「不能用」，也不等于「能用」。**
4. **不给检测方法**——法规只给限值，方法在 AOAC / BAM / 厂商 IBR 文件里，本件一律「转引未收」。

## 6. 蒸馏范围与形态（用户已确认）

- **范围**：**全量 154 条款**，但**分层主次**——通用效力层 + 高风险重点类逐条展开；长尾物质（尤其 §172.510/§172.515 名录）只做「查表导航 + 定位规则」，不逐物质展开。
- **形态**：新增 **CAP-31 `direct-food-additives` 来源路由入口 + 子卡**，口径升级为**第八套法规编号〔§ 172.xxx〕/ 二十三类不可混引**。
- **不可逐字引用区**：16 张重建表格的数值、§172.510/§172.515 名录、全部 IBR 引用的外部规格文件。
