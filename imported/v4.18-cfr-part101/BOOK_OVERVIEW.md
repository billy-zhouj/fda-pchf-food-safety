## 1. 结构 (Structural)

### 类型
**法规正文 / 义务清单型规范**——不是方法论手册。它不给「怎么做危害分析」，而是把「标签上必须写什么、必须怎么写、什么话不能说、什么时候可以不说」逐项写成可执法的法定义务，并把判定阈值、豁免条件、请愿程序固化在条款里。

### 一句话主旨
凡供人食用并销售的食物，除非落入条款列举的豁免，其标签与 labeling 必须按 Part 101 规定的位置、格式、术语与显著性，载明身份/配料/净含量/厂商/营养信息，并且任何营养或健康声称只能在该法规授权的框架内作出，否则构成 FD&C Act §403 意义上的 misbranding（错标）。

### 骨架（7 个一级论点及其关系）

1. **标签的空间与形式底座**（Subpart A 前半）：§101.1 主展示面 PDP（含面积计算 a/b/c）、§101.2 信息面板、§101.3 品名、§101.4 配料表（按重量降序、通用名、§101.100 豁免例外）、§101.5 厂商名址、§101.7 净含量、§101.15 显著性、§101.18 misbranding 总纲。决定「信息放哪里、写多大多清楚」。
2. **营养信息体系**（§101.9 为核心，占 1,993 行）：(a) 普遍义务 + (j) 豁免清单；(b) serving size 由 §101.12 RACC 推导；(c)(d) 强制/自愿营养素与 Daily Value；(f)(j)(13) 小包装与简化格式；§101.10 餐馆食品声称触发的营养标签；§101.11 连锁餐饮标准菜单项卡路里（ACA §4205）；§101.36 膳食补充剂专用营养标签；§101.42–45 生鲜果蔬鱼的**自愿**营养标签与 20 种最常消费清单。
3. **参考量 RACC 表**（§101.12，约 6,118 行 / 113 页）：Table 1（婴幼儿与幼儿）、Table 2（一般食品）把「产品类别 → RACC → label statement」钉死；RACC 是 serving size、声称资格、disqualifying level 的共同分母，**但文本层是流式列值，不可逐字引数值**。
4. **声称的三层闸门**（§101.13 + §101.14 + Subpart D/E/F）：§101.13 营养素含量声称通则（express / implied、相对声称、婴幼儿禁用）；§101.14 健康声称通则（significant scientific agreement、disqualifying levels、须经授权）；Subpart D §101.54/56/60/61/62/65/67/69 给逐词阈值与请愿；Subpart E §101.70–83 给 12 类**已授权**健康声称的模型措辞与适用条件；Subpart F §101.91 gluten-free、§101.93 膳食补充剂免责声明、§101.95 fresh 用语。
5. **特定品类与风险警示**（Subpart B + §101.17 + §101.8）：§101.22 香料/调味/色素/化学防腐剂（可统称 vs 须具体名）、§101.30 果汁百分比声明、§101.17 自加压容器/极低热量蛋白膳食/铁含剂/亚硫酸盐/**未巴氏果汁 (g)**/安全操作声明等强制警示、§101.8 自动售货机卡路里声明。
6. **豁免体系**（Subpart G）：§101.100 免的是 **FD&C Act 403(i)(2) 配料表要求**（含 incidental additives 与 10 ppm 亚硫酸盐可检出阈值），§101.108 允许在 FDA 书面提案获批下做**临时标签实验豁免**；另 §101.9(j) 才是营养标签的豁免清单——两套豁免对象不同。
7. **附录层**：Appendix A [Reserved]；B 图形增强；C 生鲜果蔬 Nutrition Facts；D 熟鱼 Nutrition Facts——均为图形示例，转换后文本层不可逐字引用。

**论点之间的关系**：**层层套嵌 + 条件分流**。1 是所有标签的物理载体；2–3 在其上叠加强制信息；4 对「可说什么的形容词」另设授权闸门；5 对特定品类追加警示/声明；6 在每一层开各自的豁免口（**豁免对象互不通用**）；7 是格式示例。5 与 4 并列，6 横切前五层。

### 作者（立法者）要解决的核心问题
把 NLEA / DSHEA / FALCPA / ACA 等国会授权，转化成**可被检查、可被起诉、可被量化核对**的标签规则：既让消费者能横向比较（统一 serving size、统一 Nutrition Facts 格式），又防止厂商用「低脂」「健康」「含果汁」「无麸质」等未经证实的暗示绕开比较基准。

## 2. 解释 (Interpretive)

### 关键术语（法规本人的用法）

| 术语 | 法规定义 / 判据 | 和常识用法的差异 |
|---|---|---|
| labeling vs label | §201(n) 的 labeling 含**随附的全部文字、图形、宣传物**（本 part 大量条款写 "label or in labeling"） | 中文「标签」常被理解成只贴瓶身那张；实际广告、菜单、随附单张都在内 |
| principal display panel (PDP) | §101.1：最可能在零售陈列条件下被展示的那部分标签；须大到能清晰容纳全部强制信息；面积按 (a) 矩形高×宽 / (b) 圆柱 40% 高×周长 / (c) 其他形状 40% 总表面计算 | 不是「正面」的视觉直觉；圆柱容器是法定 40% 公式，且强制信息须落在这 40% 内 |
| information panel | §101.2：紧邻 PDP 右侧的那部分标签（有例外） | 位置是法定相对方位，不是任选空白面 |
| serving / serving size | §101.9(b)：由 §101.12(b) 的 RACC 推导的 customary consumption 量，不是厂商建议食用量 | **不是营养建议、不是份量自由裁量**；是监管比较基准，直接决定声称资格 |
| RACC | §101.12 按产品类别给出的参考量 | 不是工艺参数、不是危害分析输入，但被声称规则反复引用 |
| nutrient content claim | §101.13(b)(1)(2)：express（直说营养素水平）或 implied（暗示）表征 §101.9/§101.36 要求标示的营养素水平 | 「暗示」也算——品牌名、符号、vignette、第三方引用都可能构成声称 |
| health claim | §101.14(a)(1)：明示或暗示（含 heart 符号、品牌名 heart、第三方文献引用）表征某物质与疾病/健康相关状况的关系 | 与营养素含量声称是两套授权体系，不可互套 |
| significant scientific agreement (SSA) | §101.14(b)：合格科学专家间的显著科学一致，是健康声称可获授权的前提 | 不是「有论文支持」；是法规级证据门槛 |
| disqualifying level | §101.14(a)(4)/(b)：食品中特定营养素超过阈值即**丧失**作健康声称的资格 | 声称资格是「先过负面门槛」而非只满足正面条件 |
| gluten-free | §101.91(a)(3)：不含特定谷物/成分，且不可避免的麸质存在 **below 20 ppm** | 是定量阈值定义，不是「无添加」营销词；与 Ed.5 的 allergen-free 声明规则不同源 |
| incidental additive | §101.100(a)(3)：存在量不显著且在该食品中无技术或功能效果的添加剂，可免于配料表申报 | 「免申报」有功能效果前提；亚硫酸盐另按 (a)(4) **10 ppm 可检出**判，不因「 incidental 」自动免 |
| misbranding | §101.18：标签/标签说明中虚假或误导性陈述使食品错标（FD&C Act §403） | 与 Part 117 的 **adulteration（掺假，§402）** 是两条独立执法钩子 |

### 核心命题（用自己的话）

1. **标签义务是「默认适用 + 列举豁免」结构**：§101.9(a) 明写除 (j) 豁免外一律提供营养信息，举证责任在主张豁免者；不能用「我们产品特殊」概括免标。
2. **位置、格式、显著性本身就是义务**，不是排版偏好：PDP 面积公式、信息面板方位、§101.15 的 prominence 都是可开观察项的法定要件。
3. **所有比较都锚定 serving size / RACC**：声称阈值、Daily Value、disqualifying levels 都以 RACC 或 per labeled serving 表述；脱离份量谈「低脂/高纤」无意义。
4. **声称是「负面清单 + 正面授权」双闸**：营养素含量声称须符合 §101.13 通则与 Subpart D 逐词定义；健康声称须 SSA + 不超 disqualifying level + 落在 §101.72–83 已授权模型内；Subpart F 的 gluten-free / fresh 又各自定义。
5. **暗示与明示同等受管**：品牌名、心形符号、第三方引用、vignette 都可能构成 claim（§101.14(a)(1)），这是最易漏判的一类。
6. **警示声明按风险场景逐项立法**：自加压容器、极低热量蛋白膳食、铁含剂、亚硫酸盐、未巴氏果汁、肉禽安全操作各有独立 (a)–(h) 款与各自豁免，不得「借」另一款的措辞或条件。
7. **豁免是「针对哪一条义务」的精确豁免**：§101.100 免的是 403(i)(2) 配料表，§101.9(j) 免营养标签，§101.108 免的是经 FDA 批准的临时实验——三者不能互相替代，也不等同于 Part 117 的 qualified facility 等**主体豁免**。
8. **与 PCHF 是并行法源，不是同一义务的两面**：Part 117〔§ 117.135(c)(2)〕要求把「标签控制」作为过敏原预防控制来**管理**（确保标签内容正确、正确标签用到正确产品）；Part 101 规定标签**内容本身**该是什么。企业两套都要满足，条款号不得互引。
9. **〔§ 101.17(g)〕是本次最直接的接口**：未经足以防止/减少/消除病原的工艺处理的果汁须带警示声明，与 21 CFR Part 120〔§ 120.24〕5-log 法定要求、CP 7303.847（CAP-27）构成「工艺义务 → 标签义务 → 检查取证」三层；警示声明**不替代** 5-log，做了 5-log 也**不自动免除**所有标签义务。
10. **数值型阈值散落且各有法源**：20 ppm（gluten-free）、10 ppm（亚硫酸盐可检出）、5 calories / RACC（§101.60 等「free」类门槛）、40%（PDP 圆柱面积）、120 °F（自加压容器警示）——它们是不同条款的不同判据，不可混算。

### 论证链
国会授权（FD&C Act §403 / NLEA / DSHEA / FALCPA / ACA §4205）→ 法规把它拆成「载体规则（Subpart A）＋强制信息（§101.9 等）＋比较基准（§101.12 RACC）＋声称授权（Subpart D/E/F）＋风险警示（§101.17）＋豁免（Subpart G）」→ 用定量阈值（RACC、DV、20 ppm、10 ppm、disqualifying levels）与模型措辞把「模糊形容词」变成可核对事实 → 用 misbranding（§403）与请愿程序（§101.69/70）提供执法与变更通道 → 条文末尾 FR citation 记录每次修订。证据类型：法定条文 + 定量阈值 + 授权清单 + 引用并入（incorporation by reference）。

## 3. 批判 (Critical) ★

### 时代局限
- **快照而非编纂版**：本件是 eCFR 2026-11-05 现行快照，自述 `authoritative but unofficial`；与 4-1-25 Edition 年度编纂版、GPO 正式文本的排版与条款编号可能不同。§101.12 的 RACC 表、DV 值属持续修订对象，引用具体数值须复核快照日期与 FR citation。
- **滚动修订造成「同 part 不同年代」**：条文末尾 FR citation 从 42 FR 14308 (1977) 一直延到 88 FR 17718 (2023)；§101.9 的 2016 营养标签新规、§101.11 的 ACA 菜单标签、§101.91 的 2013 无麸质规则各自的合规日期与过渡期不能从本文直接读出。
- **引用并入的外部法源不在本件**：§104.20 强化政策、21 CFR part 102 通用名、part 130 标准身份、part 105 / 105.66、AOAC / 检测方法、1 CFR part 51 并入材料、FD&C Act 全文——一律「转引未收」。

### 立场盲点
- **监管者/执法视角**：默认企业有定量检测、营养数据库、法规事务与标签审核能力；对小微企业只给 §101.9(j) 类豁免，未给出「如何低成本取得可靠营养数据」的方法。
- **美国单一市场**：全部锚定 FD&C Act 与美国消费调查数据（1977–78 / 1987–88 NHANES 2003–08）；对中国读者需映射到 GB 7718 / GB 28050 / GB 13432 等，且「营养标签强制 + 声称正面授权」的逻辑与国内体系并不一一对应。
- **把「标签正确」当作消费者保护的主渠道**：本 part 几乎不处理「标签正确但产品被污染」或「标签错误但产品安全」的风险分配，这部分要靠 Part 117 / 402 掺假条款另行解决。

### 未被证明的假设
- 假设 RACC 能代表真实消费量；法规自己承认数据来自 1977–1988 消费调查并用 NHANES 2003–2008 更新，但单份包装、多份包装与「一次吃多少」的行为差异仍会击穿该基准。
- 假设消费者会读并理解 Nutrition Facts 与 %DV；§101.9 的格式规则极细，却无法证明格式优化真的改变选择。
- 假设 SSA 门槛能同时保证科学准确与不过度限制商业表达；§101.70 请愿程序与 §101.71「未授权声称」清单正是该张力的产物。

### 最强反对意见
这套规则把海量合规成本压在「排版、字号、份量换算、逐词声称审查」上，而真正造成健康危害的往往是生产过程失控（Part 117 领域）或 deliberately misleading 的整体营销印象；一张完全合规的 Nutrition Facts 完全可能伴随高危产品。反对者会说：Part 101 是「信息合规」而非「食品安全」，把它并入以危害分析为核心的 PCHF 技能包，若不做严格的**效力层与接口标注**，反而会诱导使用者把「标签合规」误当成「安全合规」——**这正是本次升级必须写进每个能力卡 B 段的红线**。

## 5. 与既有技能包的接口清单（阶段 0 增量判定）
