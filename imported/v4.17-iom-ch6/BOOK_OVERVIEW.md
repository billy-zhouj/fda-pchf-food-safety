## 1. 结构 (Structural)

### 类型
**程序性实操手册（SOP manual）**。它不提出可争辩的理论命题，而是把一套法定授权下的判定动作、顺序、记录字段和责任分工固定下来。读者是 FDA 入境审查员 / 调查员，不是进口商。

### 一句话主旨
**FDA 人员依据 FD&C Act §801 等授权，按"入境申报 → 电子审查 → 现场查验/取样 → 可采性判定 → 放行或扣留/拒绝 → 违规调查"的固定链条，对拟入境的 FDA 监管商品作出可辩护、可追溯的准入决定。**

### 骨架（主要部分及其关系）

1. **6.1 Imports General（法定边界与前置条件）** — §801 授权、与 CBP 的分权、6 类入境类型（Formal / Informal / Mail / Personal Baggage / Manual / IFE）、食品事先通知（Prior Notice）、CBP 与 FDA 的入境处理分工、VQIP、照片证据标识与存储。
2. **6.2 Entry Review（电子审查决策门）** — 审查员职责、初审排序（QAV > NQV、ITACS 优先、紧急/易腐最高）、May Proceed 及其撤消、请求现场查验/取样（LEX/FEX/SAM）、单据索取 DRQ 与 ITACS 上传、条件放行期、向 Compliance Branch 提交扣留建议（DER 用于 DWPE，DTR 用于其他）。
3. **6.3 Field Examination（现场查验执行）** — 排程；按产品类别分列的现场与标签查验要点（食品/化妆品、药品、器械、生物制品、动物产品、辐射健康、烟草）；查验结果字段（Date Completed / Location / Remarks / Summary / Exam Class / Record Time / Next Steps）；撤消 IB Release。
4. **6.4 Import Sample Collection（取样与证据链）** — 一般政策、无法取样时的处置、取样前程序、取样技术、样品采集报告 SCR 逐字段规范、报告更新、附加样品 ADS、国内进口特殊样品 SDI。
5. **6.5 查验/取样后的处置链（法律后果）** — 无违规 → Notice of Release；有违规 → Notice of FDA Action - Detained（一般 10 个工作日听证）→ 改标/重整申请（Form FDA 766 + bond）→ 批准后复核 → 条件满足放行 / 不满足拒绝 → Refusal of Admission（90 天内出口或销毁、CBP 4647 红交货）→ 监管费用（FDA 790）→ Bond Action。
6. **6.6–6.7 进口调查与报关行评估（事后追责）** — 进口调查的作用与报告时限（末次调查活动后 10 个工作日出 memo、5 个工作日内背书）；四类违规模式（Failure to Hold / Substitution / Importer Misdeclaration / Filer Misdeclaration），其中 Failure to Hold 给出 8 步调查清单及健康危害、DWPE 的加重步骤；定期 filer evaluation 监控申报数据准确性。
7. **6.8 FSVP（对进口商的直接检查）** — 检查前准备与参考、检查权限、检查活动（含 FSVP 记录审查）、观察项 Form FDA 483a 的编制与签署政策、报告（T-EIR / EIR）。
8. **6.9 Glossary（78 条术语）+ Exhibit 6-1~6-4（表单）** — 为上述所有判定提供口径定义与文书载体。

**论点之间的关系**：**严格递进 + 少量并列**。6.1→6.2→6.3/6.4→6.5 是一条不可逆的时间链（每步的产物是下一步的输入）；6.6–6.8 是对链条失效或延伸的**并行追责支路**；6.9 是横切全链的口径层。6.3 内部按产品类别是并列关系。

### 作者要解决的核心问题
在进口量远大于查验能力的约束下，**如何用有限的现场资源、统一的判定口径和完整的书面证据，把"某批货是否可合法入境"这个决定做得既合法又可被复核、可在听证和后续执法中站得住**。

## 2. 解释 (Interpretive)

### 关键术语（作者本人的用法）

| 术语 | 作者的定义 | 和常识用法的差异 |
|---|---|---|
| **Entry / Line** | 一次报关中可被单独审查、单独作出可采性判定的最小单元（entry line item） | 不是"一批货"；一个 entry 可含多个 line，各 line 可分别放行/扣留 |
| **May Proceed** | FDA 在电子审查后允许货物进入流通的**放行决定**，不是"可以开始审查" | 字面易误解为"准许继续办理"；实为终局性放行动作，且可 rescind |
| **Conditional Release** | 货物先交进口商控制、但**仍处 FDA 管辖下**，须保持可召回状态直到 FDA 放行 | 不是"有条件地合格"；附的是 redelivery bond 义务 |
| **Failure to Hold** | **未获 FDA 放行即已分销**货物；定义为"无放行而分销"，而非"货物被移出港区" | 关键在"分销"而非"位移"；位置变化本身不构成该违规 |
| **DWPE** | Detention Without Physical Examination：基于历史/进口警报等证据，无需实物查验即可扣留 | 不是"不检查就放过"，恰恰相反是"不检查就扣住" |
| **DER / DTR** | 审查员提交扣留建议的两种 work type：DER 用于受 DWPE 约束者，DTR 用于其他疑似违规 | 二者不是严重度分级，而是**触发依据**的分流 |
| **Prior Notice** | 食品/动物饲料抵达前须经 FDA 电子接收并确认的预先通报（按运输方式 2/4/8 小时） | 不是报关单的一部分；是独立的、有确认回执的法定前置义务 |
| **Reconditioning** | 在 FDA 批准并监督下，以改标、重整等方式使不合格品达到可采状态（Form FDA 766） | 不是企业自行返工；未经批准的自行整改不产生放行效力 |
| **Refusal of Admission** | 拒绝入境通知；触发 90 天内出口或销毁、CBP 4647 与保证金行动，FDA 档案直到销毁/出口证明到手才关闭 | 不是流程终点；之后还有销毁/出口核验与 bond action |
| **PREDICT** | 风险评分与规则标记的电子筛查系统，审查决定的重要输入但可被有理由的 May Proceed 覆盖 | 不是自动判决；与 PREDICT 结果相悖的放行必须写明理由 |
| **FSVP Importer** | 依 FSMA 对境外供应商履行验证义务、并须接受 FDA 记录审查的进口商 | 与"Importer of Record"（CBP 关税责任主体）不是同一概念 |
| **A of C / IUC** | Affirmation of Compliance（合规申明）/ Intended Use Code（用途代码），申报数据的判定字段 | 看似元数据，实为可采性判定依据，填错须更正后 rescreen |

### 核心命题（用自己的话）

1. 可采性判定必须由**有培训资质的人员**、基于**电子与纸质单据 + PREDICT 筛查 + 进口警报 + 历史合规记录**共同作出，不能只凭其中一项。
2. 任何影响 PREDICT 筛查的数据错误（制造商、发货人、产品代码、数量）都必须**更正、指派责任方、保存并重新筛查**，否则后续所有判定建立在脏数据上。
3. 与筛查结果相悖的放行、请求扣留、请求现场工作三类决定，都必须在系统备注中写出**具体理由**；"May Proceed"／"N/A" 这类空泛备注被明确禁止。
4. 放行不是不可撤回的：May Proceed 与 IB Release 都有明确的**撤消程序**；误放行后须立即通知 CBP 请求 redelivery，且 CBP 只有自条件放行期结束起 **30 天**窗口。
5. 扣留建议要按**触发依据**分流到 DER 或 DTR，并提交 Compliance Branch，而不是审查员自行作出终局扣留。
6. 现场查验与取样的价值一半在结果、一半在**证据链**：照片须用政务设备拍摄、逐张标识（entry/line、日期、检查员缩写、描述、序号）、上传至系统，打印件须把标识永久固定在照片上下方而非照片上。
7. 样品采集报告（SCR）的字段（Date Collected / Episode / Submitted To / Quantity / Units / DescText / Hand Ship / Remarks / Record Time）是**法定记录质量的载体**，逐字段都有规范；SDI 样品还需标签描述、官方封条 FDA 415a 与采集人 ID，以便 FDA 在检出违规时启用国内管辖权。
8. 发现违规后的路径是**听证 → 举证 → 改标/重整 → 复核 → 放行或拒绝**，每一步都有对应文书（Notice of FDA Action、FDA 766、Importer's Certificate、Notice of Release / Refusal、FDA 790）。
9. 重整失败后原则上不给第二次机会，除非**修订后的方法能合理保证成功**；合格部分放行时，不合格部分仍须销毁或再出口并单独出具拒绝通知。
10. 拒绝入境后 FDA 的公共健康责任**延续到货物被销毁或出口为止**，档案不因发出通知而关闭。
11. "Failure to Hold"是最典型的违规模式，调查有固定 8 步（单据 → 分销记录 → 授权人 → 是否知悉健康危害 → 授权人说明并作成 affidavit → 历史检索 → 协调 CBP 4647 → 核定 bond）；存在重大健康危害或 DWPE 情形时追加召回/公共警告协调。
12. 进口调查的价值在于把个案证据转成 CBP 制裁（行政扣押、民事罚款、取消条件放行特权、保证金行动）或 OCI 刑事调查的输入，而非止于本批货的处置。
13. FSVP 检查的对象是**进口商的记录**，观察项走 FDA 483a、报告走 T-EIR/EIR，是与货物查验并行的独立合规轨。

### 论证链
作者不"论证"，而是**以法定授权为公理、以流程顺序为推导**：§801/§536/19 CFR 151.4 → 授权 FDA 查验与取样 → 由此产生"谁审查、按什么数据审查"（6.2）→ 审查后只能落入有限几个动作（放行/现场/扣留建议）→ 每个动作产生必须留痕的文书与字段（6.3/6.4）→ 文书汇总成听证可用的证据 → 证据支撑 §801 下的扣留、拒绝、改标、保证金（6.5）→ 对规避链条的行为启动调查与制裁（6.6/6.7）→ FSVP 把合规义务前移到进口商（6.8）。支撑材料是法条编号、CBP/FDA 表单编号、内部 SOP/CPGM/RPM 交叉引用和逐字段的填写规范，而不是案例推演。

## 3. 批判 (Critical) ★

### 作者的时代局限
- **强绑定 2026 年的 IT 系统与内部文书**：PREDICT、OASIS、ITACS、eNSpect、ACE、ER Job Aid、SOP-000217、WI-000618 等界面/流程/SOP 编号会随系统改版失效；本章 2026 版是快照而非稳定规则。
- **大量结论靠跨章引用承载**：IOM 4.x（取样）、5.x（证据/报告）、8.x（调查备忘录）、RPM Chapter 9（放行/听证/拒绝/保证金）、各 CPGM 才是细则所在；单读第 6 章会得到一个"有骨架、缺细则"的闭环幻觉。
- 附件 Exhibit 6-1~6-4（Notice of FDA Action、FDA 766、FDA 790、FDA 463a）在本次 PDF 中为扫描图像，无法从文本层提取字段，蒸馏时对表单细节只能标注"需查原件"。

### 作者的立场盲点
- **全篇是监管者视角，不是企业视角**：写的是"FDA 如何作出并执行决定"，不写"进口商/境外生产商如何准备举证、如何避免被扣、如何回应 483a"。若企业直接照搬，会把"检查清单"误当"合规义务清单"。
- **组织前提被隐去**：默认使用者有 FDA 授权、系统权限、Division / Compliance Branch / OCI / CBP 的协作通道。企业或个人没有这些前提，大部分步骤无法执行，只能作"理解对方判定逻辑"之用。
- **几乎不谈相对方的权利与救济成本**：听证被描述为"informal meeting"，但对进口商而言是举证、时间、货物滞期与保证金风险的集中点；手册不提供这些权衡。

### 未被证明的假设
- **把自由裁量当自明**：文中密集使用 "as warranted" / "where appropriate" / "should" / "if the facts warrant"，却很少给出裁量判据。例如"请求扣留 vs 请求现场工作"的选择标准、"adverse conditions"的阈值、照片"warranted"的情形，都留给分部惯例。
- **假设电子数据可靠且完整**：整套流程建立在 filer 传输的 A of C、IUC、产品代码、数量准确之上；6.7 的 filer evaluation 只是周期性抽样监控，并未论证抽样足以支撑逐批判定。
- **假设"有记录＝有合规"**：SCR 字段、备注、照片标识被高度规范化，但记录齐备与实际可采性之间的差距未被讨论。

### 最强反对意见
> **IOM 是内部操作指导，不是法规，也不是可对外主张的法律依据。** 真正的义务来自 FD&C Act §801、21 CFR Part 1（含 Prior Notice、FSVP）、19 CFR 113.62 等；IOM 中的 "should" 与 "as warranted" 属机构裁量，不构成对企业的法定义务，FDA 在个案中偏离 IOM 通常也不产生可诉的权利。因此，把本章蒸馏成"合规规则引擎"会系统性高估其法律位阶——正确的定位是**"理解 FDA 判定逻辑与举证要求的操作地图"**，任何结论都须回到法条与当前版本 IOM/RPM 复核。

> **以上批判会直接成为下游能力卡的 Boundary (B) 字段来源。**

## 4. 应用潜力 (Applicability)

### 可 skill 化的内容
- [ ] 入境类型 / 事先通知（Prior Notice）适用性判定：时限 2/4/8 小时、15/30 天上限、豁免清单
- [ ] 入境审查决策树：初审排序 → May Proceed / 撤消 / 请求现场工作 / 请求扣留（DER vs DTR）
- [ ] 数据完整性与重新筛查规则（更正 → 指派责任 → 保存 → rescreen）
- [ ] 扣留与放行后的处置链：Detained → 听证 → FDA 766 改标/重整 → 放行 / 拒绝 → 90 天出口销毁 → Bond Action
- [ ] 条件放行与 Failure to Hold 的判定及 8 步调查清单（含健康危害 / DWPE 加重步骤、30 天 redelivery 窗口）
- [ ] 现场查验与标签查验按产品类别的检查要点、Exam Class 与结果字段
- [ ] 进口取样与证据链：SCR 九字段、照片标识规则、ADS / SDI、官方封条
- [ ] 四类进口违规模式的识别与调查要点（含 importer/filer misdeclaration 区分）
- [ ] FSVP 检查准备、记录审查、483a 观察项与 EIR 报告
- [ ] 进口术语口径判定（78 条，用于消除"扣留/放行/条件放行"等概念混淆）
- [ ] 文书—环节举证矩阵：每个环节应产出哪张表 / 哪个字段 / 谁签字
- [ ] **镜像视角**：从 FDA 判定动作反推进口商/境外生产商的迎检举证清单（属 A2 应用层，需在卡中明确标注为推导而非原书主张）

### 不适合 skill 化的内容
- 系统界面的点击级操作、内部 SOP/Job Aid 编号清单、组织职责与工时上报规定（随版本变化、无迁移价值）
- Exhibit 6-1~6-4 的表单版式本身（扫描件，无文本层，只能作为"需查原件"引用）
- 各产品类别查验要点中的纯列举性清单（可作为某张能力卡的 example，不独立成卡）
- 法条编号的罗列（作为 Boundary 的复核锚点保留，不独立成卡）

### 预估 skill 数量
**约 8–12 个能力单元**（最终由阶段 1.5 三重验证 + 1.6 晋级门决定，这里只是粗估）。预计其中 2–4 个能满足独立晋级判据，其余留在来源路由入口内作为能力卡。

### 优先级排序（按"最能赋能使用者"的角度）
1. **入境审查决策树 + DER/DTR 分流**（最高频的判定动作，预测力最强）
2. **扣留→听证→重整→拒绝的处置链与文书矩阵**（时间窗与文书一旦错，后果不可逆）
3. **Failure to Hold 判定与调查清单**（最典型的违规模式，且与"条件放行"概念强绑定）
4. **FSVP 记录审查与 483a/EIR**（对进口商最直接、与用户既有 HACCP/食品安全工作衔接）
5. **Prior Notice 适用性判定**（时限硬约束、可机械判定）
6. **取样与照片证据链规范**（可审计、字段化程度高）
7. 其余（术语口径、现场查验、filer evaluation、违规模式全谱）
