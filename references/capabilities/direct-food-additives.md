# 21 CFR Part 172 直接食品添加剂许可、限量与规格判定链（direct-food-additives）

*来源分层：本卡取用**单套法规正文**——21 CFR Part 172《Food Additives Permitted for Direct Addition to Food for Human Consumption》，eCFR 导出 PDF（Prince 16.2，178 页 / 198 书签 / 154 条款 / 9 Subpart），页脚自述 `This content is from the eCFR and is authoritative but unofficial`，即**权威但非 GPO 正式文本**。它是**联邦法规正文（最终规则、具法律约束力）**，法源含 FD&C Act §201(s)（food additive 定义）、§402(c)、§409、§401（标准身份），条文依据 `21 U.S.C. 321, 341, 342, 348, 371, 379e`。与 PCHF 行业指南、L.mono 草案、SECG、过敏原 Ed.5、Food Defect Levels Handbook、CPGM 7303.040、CP 7303.050 / 7303.070 / 7303.842 / 7303.847 / 7303.878、IOM 2026 Ch.4 / Ch.5 / Ch.6、21 CFR Part 101 / 108 / 113 / 114 / 117 / 120 / 123 分层，不得混引。*

*⚠ **效力层与版本口径**：本卡是 v4.19 为本包新增的**第二十三来源**，原「二十二类不可混引」自本轮起为**二十三类不可混引**；〔§ 172.xxx〕是全包**第八套独立法规编号**，与〔§ 101.xxx〕〔§ 108.xxx〕〔§ 113.xxx〕〔§ 114.xxx〕〔§ 117.xxx〕〔§ 120.xxx〕〔§ 123.xxx〕**并列**——各管各自义务，不是上下位、不是新旧替代。Part 172 管**许可与限量/规格**（某物质能不能用、用在什么食品、用多少、须符合什么纯度规格）；Part 101 管**标签内容本身**（CAP-30）；Part 117 管**过程预防控制**（CAP-01～CAP-09 等）。§172.5(b) 明文——**「有安全使用条件的法规，不得解释为免除该物质遵守本法其他任何规定」**，即：用了被许可的添加剂，仍要符合标签义务与过程控制义务。⚠ **添加剂被许可 ≠ 产品安全**：许可层（Part 172）与掺假层（402）、过程层（Part 117）是彼此独立的判定。本件是 **2026-11-05 现行快照**，不是 4-1-25 Edition 年度编纂版、不是新规发布日；条文末尾 FR citation 才是修订出处，凡涉具体数值须复核快照日期。全卡引用统一写〔§ 172.xxx〕+ `[pdf-page N]`，不得写成〔§ 117.xxx〕式或「21 CFR 172.x（指南）」。*

*本卡定位：**1 个可发现入口 + 5 个能力单元**，由本入口卡按意图路由到 `references/capabilities/additives/` 下 5 张 RIA++ 子卡（沿用 v4.18 CAP-30「一个来源 = 一张 CAP 入口卡」惯例）。**V05 是横切口径层/效力层，不单独抢路由**，须依附 V01–V04 业务卡使用。与既有 CAP 的关键分流（**注意「添加剂」字形吸附**）：凡问**某物质能不能用、用多少、纯度规格** → **本卡**；凡问**配料表怎么写、PDP/信息面板、营养标签、声称** → **CAP-30**；凡问**危害分析/预防控制/记录/召回** → **对应 PCHF 卡（CAP-01～09）**，添加剂许可不替代过程控制；凡问**包装材料迁移的间接添加剂、GRAS 认定、Part 170/171/180** → **本包未收（标「转引未收」）**；凡问**过敏原交叉接触排产** → **CAP-05**。*

**数字陷阱**：`75 ppm`（麦芽溴酸盐）与 `25 ppm`（成品溴化物）是同一物质的不同载体、不同计量对象，混算即整条判定错；`20 ppm` 出现在氯化亚锡（以 Sn 计）与 BHA 干混料冲调后（§172.110(c)(3)）两处，基准完全不同；亚硝酸盐 `100–200 ppm` 是**区间**（有下限也有上限），与只给上限的条款方向不同；Olestra 的四组补偿量单位各异（mg/RE/IU/µg），不可互算。

## 与既有 CAP 的分流（不得混引）

> 注：「二十八类不可混引」自 v4.19 起含 21 CFR Part 172。本卡〔§ 172.xxx〕引用不得与〔§ 101.xxx〕等七套法规正文、FDA 各类指南、CPGM/CP/IOM 检查程序交叉混引；遇边界问题回 V05。

- **CAP-30 `food-labeling-requirements`（Part 101 标签内容）**：管配料表怎么写、PDP/信息面板、营养标签与份量、声称授权、警示声明、标签豁免。本卡只给「添加剂许可与限量层」自带的标签义务（添加剂名称、足够使用说明、载体/中间品浓度披露、用途锁定声明、PHENYLKETONURICS 警示语、Dietarily insignificant）。**§172.5(b)：有添加剂许可不免除标签义务**；「添加剂合规」与「标签合规」是两套判定，条款号不得互引替代。
- **CAP-01～CAP-09（危害分析、预防控制、cGMP、供应链、召回等）**：管**生产过程**的危害分析与预防控制、过敏原控制、记录保存。§172.5(b) 明文——用了被许可的添加剂，仍要做危害分析、仍要符合 CGMP、仍要控制过敏原；生物类抗菌剂（§172.785）能否替代或补充环境病原控制方案属过程层决策。**添加剂许可不替代过程控制**。
- **CAP-15 `defect-action-levels`（缺陷行动水平）**：给 402(a)(3) 掺假裁量阈值出处。本卡的限量是**许可红线**（成品不得超），与缺陷行动水平**不同轨**；`total residue` 不是缺陷水平。
- **CAP-14 `cgmp-compliance-guide`（cGMP 合规分诊）**：管 FDA 指南 should/recommend 对企业是否必须做、资料四层效力栈。本卡 V05 的效力层是**法规正文之间的编号并列**（八套编号）与法规＞指南＞检查程序的位阶；两者来源不同，不可因「should 怎么读」混引。
- **CAP-26/CAP-27（果汁 HACCP / 检查程序）**：本卡不涉果汁；若问「多栅栏工艺」类条款，注意 Part 172 的工艺参数（§172.177 烟熏鲢）与 Part 120 的 5-log 是**不同法源**的同类结构，可作类比但**不得互相套用条款号**。
- **CAP-29 `iom-imports-procedure`（IOM 2026 Ch.6）**：给进口扣留/改标重整的 **FDA 内部作业链**（Form FDA 766、DWPE、Refusal）。添加剂合规的**实体判定依据**部分回到 Part 172，但 IOM 不创设企业义务、其 `must/shall` 约束 FDA 内部作业。
- **本包未收（标「转引未收」）**：21 CFR Part 170（food additive petition 程序）、Part 171、Part 175–178（间接添加剂）、Part 180（临时许可）、Part 182/184（GRAS）、Part 102（通用名）、part 105（特殊膳食）、FD&C Act 全文、9 CFR 430.1、40 CFR 725.421(d)、FCC 各版正文、AOAC/厂商检测方法正文、ATCC 菌株资料。

## 边界与判停（B 段汇总）

**反场景（不要用本卡 / 不要加载子卡）**
- 用户要**个案合规结论、法定身份判定、标签/请愿文书代写或执法结果预测** → 本卡不代写、不出结论、不判产品法定身份、不预测 FDA 执法；回条文与专业审校。
- 用户问的是**配料表命名、营养标签、声称、PDP 显著性** → 转 CAP-30。
- 用户问的是 **FSP / 危害分析 / 预防控制 / 记录 / 召回 / FSVP 主体判定** → 转对应 PCHF 卡；添加剂许可不替代危害分析。
- 用户问的是**间接添加剂（包装迁移）、GRAS 认定、添加剂请愿程序** → 本包未收，标「转引未收」。
- 把 V05（口径/效力层）当「第 6 张业务卡」独立路由 → 错误；须依附 V01–V04 业务卡使用。

**来源与位阶边界**
- **eCFR 快照，非 GPO 正式文本**：本文自述 `authoritative but unofficial`；2026-11-05 是快照日期而非修订生效日。限量属持续修订对象，引用具体数值须回 eCFR 当前版与条文末尾 FR citation 复核；不得与 4-1-25 Edition 年度编纂版混称。
- **不可逐字引用区**：① **16 张重建表格的数值**（PDF 文本层原为流式列值，按词级坐标启发式重建，跨页续表与 `Do.` 行有归属歧义）；② **§172.510（366 行）/§172.515（834 行）名录内部行**（约 30 页、上千条物质名，只可引「在/不在清单」并注明须回原文核对拼写与收录状态）；③ **全部 IBR 引用的外部规格文件内容**（FCC 页码、厂商方法、ATCC 菌株资料）。任何数值一律回原 PDF / 原文件核对。

- **最强反对意见必须保留**：Part 172 是约 150 种物质的逐条许可清单，**近三成条款把纯度规格外转**到 FCC/厂商方法（本包只能给「去哪查」而非「是什么」）。若不做严格的效力层与接口标注，把 Part 172 并入以危害分析为核心的技能包，会诱导使用者把「添加剂被许可」误当「产品安全合规」——**这是本卡与 5 张子卡 B 段共同的红线**。同时须保留另一侧反对意见：许可清单式的逐物质管理本身可能滞后于配料创新，「清单里没有」不等于「不安全」，只等于「不在本部分许可范围内、须走其他法源」。
- **二十八类不可混引**：八套法规编号〔§ 101 / 108 / 113 / 114 / 117 / 120 / 123 / 172.xxx〕并列；FDA 指南（PCHF 指南、L.mono 草案、SECG、Ed.5、Handbook）为 should 建议层；CPGM / CP / IOM 为检查员视角、不创设企业义务。冲突时法规正文为准，指南只作解释与例证。
