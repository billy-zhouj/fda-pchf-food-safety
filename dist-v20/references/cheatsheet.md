# 决策规则速查 — Hazard Analysis and Risk-Based Preventive Controls for Human Food: Guidance for Industry (Draft)

| 能力 | 一句话规则 |
|---|---|
| 危害分析方法 | 用六列工作表把危害从识别到控制落点做成可辩护的书面推演——"No"与"Yes"同等重要，发现点不等于控制点 |
| 预防控制管理组件闭环 | 每个预防控制配"监控→纠正→验证→记录→再分析"闭环——偏差默认自上次合格点起失控，correction 与纠正措施按"是否影响食品×孤立还是反复"分诊 |
| 工艺控制与热处理验证 | 目标菌由"包装氧环境×储运温度×最耐热"推出，削减倍数查表再用 D/z 换算，文献层+厂内热分布/热穿透取交集才是关键限值 |
| 环境病原与卫生控制 | 湿区防李斯特靠保持干燥、干区防沙门靠严格控水——同点位反复检出同型菌株即定殖信号，常规清洁无效须强化根除 |
| 食品过敏原程序 | 过敏原按"CGMP 基线→排产/清洁+标签双控制→供应链三选一"三层搭建——清洁等级由相邻产品过敏原谱包含关系决定，may contain 声明只能是被证明的控制极限之出口 |
| 化学危害与食品欺诈控制 | 化学危害按引入路径分流（设施→CGMP、原料→供应链、工艺→工艺控制），掺假签名一匹配即按欺诈处置、不看数值。 |
| 供应链验证决策 | 先做控制主体映射定验证对象，再按 SAHCODH 属性×供应商控制结构性程度定验证强度；供应商自审自证零效力。 |
| 召回计划与报告义务 | SAHCODH 一次定性三处联动（Class I 召回+24h RFR+供应商年审）；召回后先通知 FDA 再对媒体，有效性核查看"已送达+已行动"。 |
| 双法规与豁免边界 | 法规适用性按"对象×危害类别"矩阵逐格判定，两套法规取义务并集（借用不免责）；极强致死工艺可作 No 的科学依据。 |
| 权威参考表与数据使用纪律 | 参考表是先验起点不是答案——X 标记过三问检验，数值禁线性内插取更严档，模型输出须自身验证后才可当关键限值。 |
| 豁免撤销应对程序 | 收到 FDA 豁免撤销文书后按 15 日申辩 / 15 日上诉 / 120 日合规三条硬时限走完程序，盯死 FDA 10 日裁决时限并利用逾期自动撤销机制。 |
| 厂房与设备工程控制 | 厂房怎么建、设备怎么造决定污染上限——清洁只能维持设计给的水平，气流压差、排水、材质与可清洁性必须在设计阶段一次到位 |
| 人员卫生控制 | 手套不是万能——接触非食品接触面即须更换；人员控制的失效不体现为"没人洗手"，而体现为手套戴到污染、工服穿回 RTE 区、泡脚器被绕过去 |
| cGMP 合规分诊与内审索引 | 合规判定基准是法规不是指南；先按主体身份分流文件效力，再用「条款—法规结果义务—现场观察点」三列索引逐条取证，SECG 只作白话转述、不创设义务。 |
| 食品缺陷行动水平与原料验收判定 | 先分法源再查数字——法定义务是〔§ 117.110(a)〕把天然不可避免缺陷降到当前可行最低水平，Handbook 表只是 FDA 据 402(a)(3) 执法的裁量参考；低于阈值不等于合规，掺混稀释一律禁止，霉菌类缺陷须联动化学危害分析。 |
| FDA 现场检查迎检与记录举证 | 先判检查类型与三层分级，再按〔§ 117.320〕当场调得出记录——FSP 必须在现场、其余记录异地须 24 小时内可取、483 回复 15 个工作日；CPGM 7303.040 是检查员作业指导，不是企业义务清单。 |
| FDA 现场取样、样品量与阳性结果应对 | 先判这是 7303.040 检查中的哪一类 7303.050 抽样，再按 Table 2/3 与 ATTACHMENT A 看取证量——产品样按 subs、环境拭子 Listeria ≥50 / Salmonella ≥100、确认阳性一律 WGS；PART V 的执法响应是逐案建议清单，不是法定后果表。 |
| FDA 检查员权限、文书与证据链 | 先分权限层再谈配合——法定基础是 FD&C Act 704(a)(1)，国内到场出示证件并签 FDA 482、境外一般不发；483 只写事实、不引法规原文也不引 guidance 偏离，取任何实体样必发 FDA 484；15 个工作日是 IOM 与 CPGM 双出处的程序口径而非法定时限。 |
| 低酸罐头与酸化食品检查（CP 7303.070）与 Part 117 管辖分流 | 先判产品进的是 LACF、AF 还是 Keep Refrigerated 轨道，再按〔§ 117.5(d)(1)(2)〕把「part 113 管辖的微生物危害」与「仍需 PCHF 的化学/物理/金葡危害」切开；酸化食品不免 C/G；检查查的是 FCE/SID、Process Authority、温度分布与热穿透、运行中 retort、卷边与异常罐；4.40/4.65 是实验室复测触发线、4.6 才是法定边界。 |
| 低酸罐头与酸化食品的法定要求（21 CFR Part 113 / 114 法规正文）与 Part 117 并行接口 | 先用成品平衡 pH 与 aw 按〔§ 113.3(n)〕〔§ 114.3(b)(d)〕定 LACF / AF 身份，再按〔§ 117.1(c)〕并行 + 〔§ 117.5(d)(1)(2)〕双条件有限豁免切出 PCHF 义务并集；酸化食品不免 Subparts C/G；法条里是 4.6 / 0.85 / 4.0 与 1+2 年记录，不是 CP 的 4.40 / 4.65 / 24 罐；Part 108 自 v4.12 起已收（手续层见 CAP-25），part 110 正文仍未收。 |
| FSVP 进口商检查（CP 7303.878）与 Part 117 供应链程序分流 | 先判谁是 FSVPI、是不是 receiving facility 可走 deemed compliance（但 §1.509 不免），再按 CP 7303.878 看检查要哪些记录；FSVP 检查不取样、PART IV 全空；观察分级后走 483a → NAI/VAI/OAI → WL → Import Alert 99-41 Red List → §801(a)(3) 拒绝入境；21 CFR part 1 subpart L 正文转引未收。 |
| 海产品 HACCP 的法定要求（21 CFR Part 123 法规正文）与 Part 117 条件性豁免接口 | 先按〔§ 123.3(d)(e)(k)〕定 fish / fishery product 与 processing 范围，再按〔§ 123.5(a)〕默认适用 + 〔§ 117.5(b)〕双条件豁免切出义务并集；Subpart B/C 是 augments 叠加；§123.16 的例外只排一条不排整 part；§123.12 与 FSVP 是双轨互不替代；记录期是 1 年 / 2 年而非统一 3 年；part 1240 / NSSP 正文与 §117.5(c) 逐字文本仍未收（part 120 自 v4.13 起已收，见 CAP-26）；CP 7303.842 自 v4.11 起已收（检查程序层，转 CAP-24），仍不得反推法条。 |
| 海产品危害分析与控制的完整判定链（FDA 第 4 版技术指南层，与 21 CFR Part 123 法条层配对） | 按「产品描述与流程图 → Ch.3 三表识别品种相关与工艺相关潜在危害 → Ch.4–21 理解危害 → 在无控制条件下逐步判 reasonably likely to occur → Column 3/4 的 Yes/No 都写理由 → Step 11 CCP 判定树定位 → 选控制策略示例 → 定关键限值与监控四问 → 纠偏记录验证签名」 走完整条判定链；但全链只是非约束性指南建议层，凡法定义务与条款级判定一律回 〔§ 123.xxx〕/ CAP-22，二十类来源不可混引，Appendix 5 数值一律标转引未收。 |
| CP 7303.842 海产品检查程序整书导航与完整检查判定链（检查员作业层，与 Part 123 法条层、危害指南层配对） | 按「Table 1 产品/工艺风险 + Table 2 企业/进口商优先级 → 六类检查分流 → HACCP Program Evaluations → Sampling 三类与 PAC/PAF → PART IV A–G 实验室分流与 CPG 判据出口 → PART V Table 4 分级与裁量 → FIELD REPORTING 收口」走完检查判定链；但全链只是给 field staff 的 内部作业指导层，凡法定义务回〔§ 123.xxx〕/ CAP-22、危害技术判定回 CAP-23，二十类来源 不可混引，CPG / BAM / NSSP / Import Alert 等未收正文一律标转引未收。 |
| 紧急许可控制与 LACF／酸化食品注册备案（21 CFR Part 108 法规正文） | 先按 CAP-20 定 LACF／酸化食品轨道，再分工：注册（Form FDA 2541，首次从事后 10 天内／外国加工者报检前）与工艺备案（2541e／2541d／2541f／2541g，注册后 60 天内且包装新产品前）是无条件义务，紧急许可是未履行后的救济手段而非常态；Subpart A 全是工作日、Subpart B 全是日历日；国内走许可、外国走 §801 拒绝入境；记录保存四套口径不得合并。 |
| 果汁 HACCP 体系（21 CFR Part 120 法规正文）与 Part 117 条件性接口 | 先用〔§ 120.1(a)〕〔§ 120.3(j)(2)(l)〕定果汁管辖与三项排除，再按〔§ 120.5〕确认 Part 117 默认适用、〔§ 117.5(c)〕为唯一出口（**双条件 + 无限缩款**，原文 v4.14 起在包内）；果汁专项叠加 Subpart A 全套与 Subpart B 的 5-log／果面处理 E. coli 验证；两处豁免对象不同不可合并；记录复审是 7 日历天、记录期 1 年／2 年或货架期孰长，与其余六套口径互不通用。 |
| 果汁 HACCP 检查程序（FDA CP 7303.847，2010-11-02 版 / 2025-09-18 更正） | 先分主体（加工者＝HACCP 检查＋非 HACCP 覆盖；进口商＝纯记录审查且不取样），再分样品（验证仅限预期 NAI/VAI 走 847H／有因非常规／文档性只报 03847 且不计工作计划），采样量按 ATTACHMENT A 逐项对表，数值必须带层标签（5-log 法定／10·20 ppb 草案拟议／4.40·4.65 是 LACF 触发线与果汁无关），升级路径按高风险→CMS、巴氏不回应→60 天复检、病原阳性→州际判定。 |
| FDA 取样全流程作业程序（IOM 2026 Chapter 4） | 先定类别（official physical／official DOC／INV／survey／non-regulatory，五类只有前两类是 official sample），再定数量（assignment → CP → IOM Sample Schedule 三级优先，通用规则为箱数平方根且 12–36 子样），再判 702(b)（默认留分析量两倍，七项豁免逐条排，污秽样品反向必须留），表单按动作对号（482／472／484／415a／525／463a／1664；DOC 不发 484、induced/undercover/online 通常不发 482+484），封条一样一封单签名、环境拭子 24 小时到实验室，阳性结果先问「关账了吗」与「哪个 Zone 哪种菌」再谈 483。 |

> 速查只给结论；需要原文依据、案例或反例时读对应能力卡。
