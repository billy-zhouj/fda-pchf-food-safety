# 21 CFR Part 101 食品标签法定义务与判定链（food-labeling-requirements）

*来源分层：本卡取用**单套法规正文**——21 CFR Part 101《Food Labeling》，eCFR 导出 PDF（Prince 16.2，352 页 / 70 书签 / 50 条款 / 7 Subpart / 4 Appendix），页脚自述 `This content is from the eCFR and is authoritative but unofficial`，即**权威但非 GPO 正式文本**。它是**联邦法规正文（最终规则、具法律约束力）**，法源含 FD&C Act §403（misbranding）、§201(n)（labeling）、§403(q)（营养标签）、§403(r)（声称）、NLEA / DSHEA / FALCPA / ACA §4205 等。与 PCHF 行业指南、L.mono 草案、SECG、过敏原 Ed.5、Food Defect Levels Handbook、CPGM 7303.040、CP 7303.050 / 7303.070 / 7303.842 / 7303.847 / 7303.878、IOM 2026 Ch.4 / Ch.5 / Ch.6、21 CFR Part 108 / 113 / 114 / 117 / 120 / 123 分层，不得混引。*

*⚠ **效力层与版本口径**：本卡是 v4.18 为本包新增的**第二十二来源**，原「二十一类不可混引」自本轮起为**二十二类不可混引**；〔§ 101.xxx〕是全包**第七套独立法规编号**，与〔§ 108.xxx〕〔§ 113.xxx〕〔§ 114.xxx〕〔§ 117.xxx〕〔§ 120.xxx〕〔§ 123.xxx〕**并列**——各管各自义务，不是上下位、不是新旧替代。Part 101 管**标签（labeling）**，Part 117 管**生产过程的危害分析与预防控制**：Part 117〔§ 117.135(c)(2)〕要求把「标签控制」作为过敏原预防控制来**管理**（确保标签内容正确、正确标签用到正确产品），Part 101 规定标签**内容本身**该是什么；两套都要满足，条款号不得互引替代。⚠ **标签合规 ≠ 食品安全合规**：403 misbranding（错标）与 402 adulteration（掺假）是两条独立执法钩子，一张完全合规的 Nutrition Facts 完全可能伴随高危产品。本件是 **2026-11-05 现行快照**，不是 4-1-25 Edition 年度编纂版、不是新规发布日；条文末尾 FR citation 才是修订出处，凡涉具体数值（RACC、DV、声称阈值）须复核快照日期。全卡引用统一写〔§ 101.xxx〕+ `[pdf-page N]`，不得写成〔§ 117.xxx〕式或「21 CFR 101.x（指南）」。*

*本卡定位：**1 个可发现入口 + 5 个能力单元**，由本入口卡按意图路由到 `references/capabilities/labeling/` 下 5 张 RIA++ 子卡（沿用 v4.17 CAP-29「一个来源单章 = 一张 CAP 入口卡」惯例）。**V05 是横切口径层/效力层，不单独抢路由**，须依附 V01–V04 业务卡使用。与既有 CAP 的三处关键分流：**过敏原标签内容**在 `allergen-program` CAP-05（Part 117 预防控制层 + Ed.5 guidance 层），本卡只给 Part 101 的配料表/显著性/gluten-free 法条层；**果汁 5-log 工艺义务**在 `juice-haccp` CAP-26〔§ 120.24〕，本卡 V04 只给〔§ 101.17(g)〕未巴氏果汁警示与〔§ 101.30〕果汁百分比声明；**Part 117 qualified facility 等主体豁免**在 `regulatory-boundaries` CAP-09，本卡 V05 只给标签义务豁免。⚠ **触发判别（避免「标签」字形吸附）**：凡问配料表怎么写、PDP/信息面板放哪、字号显著性、Nutrition Facts / serving size / RACC、低脂高纤等声称能不能说、gluten-free 20 ppm、果汁警示与百分比声明、§101.100/§101.108 豁免 → **本卡**；凡问过敏原交叉接触排产、换产清洁验证、may contain 咨询声明、Contains 声明的 Big 9 物种范围 → **转 CAP-05 + Ed.5 guidance 层，不进本卡**；凡问 FSP 危害分析、预防控制监控、记录保存、召回计划 → **转对应 PCHF 卡**，标签合规不替代危害分析。*

## 硬数字速查

> 全部为 Part 101 **法规正文层**判据，`[pdf-page N]` 为 PDF 印刷页码。**数字相同不等于同一件事**，各款阈值不可互算。§101.12 Table 1/2 的 RACC 数值本包不可逐字引用，只可引「产品类别 → RACC → label statement」对应关系并回原表核对。

| 数字 | 含义 | 出处 | 所属单元 |
|---|---|---|---|
| **40 percent** | 圆柱或近圆柱容器的 PDP 面积＝高 × 周长的 40%；强制须出现在 PDP 的信息须落在这 40% 内 | 〔§ 101.1(b)/(c)〕[pdf-page 3] | V01 |
| **10 ppm (mg/kg)** | 亚硫酸盐「可检出量」阈值：成品中 ≥10 ppm 即不得按 incidental additive 免于配料表申报 | 〔§ 101.100(a)(4)〕[pdf-page 337] | V05 |
| **below 20 ppm** | 「gluten-free」声明的不可避免麸质上限；不是「无添加」营销词 | 〔§ 101.91(a)(3)〕[pdf-page 331] | V03 |
| **5 calories / RACC** | 「free」类营养素含量声称的基准门槛之一（水、茶、咖啡等 <5 calories per RACC and per labeled serving） | 〔§ 101.60 / § 101.65〕 | V03 |
| **50 percent / RACC** | 相对声称（`more` / `light` 等）与「unit 重量 ≤50% RACC 时按 1 或 2 个单元」的分档判据 | 〔§ 101.9(b) / § 101.54 / § 101.56〕 | V02 / V03 |
| **120 °F** | 自加压容器警示的逐字措辞 `Do not store at temperature above 120 °F` | 〔§ 101.17(a)(1)〕[pdf-page 212] | V04 |
| **400 Calories / day** | 极低热量蛋白膳食警示的适用门槛 `below 400 Calories per day` | 〔§ 101.17(d)〕 | V04 |
| **25 grams of soy protein a day** | 大豆蛋白与 CHD 已授权健康声称的模型措辞定量条件 | 〔§ 101.82(e)〕[pdf-page 325] | V03 |
| **1.3 g vegetable oil sterol esters** | 植物甾醇/甾烷醇酯与 CHD 声称模型措辞的每日两餐总量 | 〔§ 101.83〕[pdf-page 330] | V03 |
| **less than 1 percent juice** | 果汁含量 <1% 时百分比声明的法定措辞 | 〔§ 101.30(b)〕[pdf-page 225] | V04 |

**数字陷阱**：20 ppm（gluten-free，§101.91）与 10 ppm（亚硫酸盐可检出，§101.100(a)(4)）是不同条款、不同对象、不同法律后果，混算即整条判定错；40%（PDP 面积公式，§101.1）与 50%（份量/声称分档，§101.9(b)/§101.54）也不相干；〔§ 101.17(g)〕警示**没有**数值阈值，其判据是「是否经 (g)(7) 所述工艺处理」这一**工艺状态**，不是某个 ppm 或 log 数。

## 与既有 CAP 的分流（不得混引）

> 「二十二类不可混引」自 v4.18 起含 21 CFR Part 101。本卡〔§ 101.xxx〕引用不得与〔§ 117.xxx〕等六套法规正文、FDA 各类指南、CPGM/CP/IOM 检查程序交叉混引；遇边界问题回 V05。

- **CAP-05 `allergen-program`（过敏原程序）**：管**厂内**交叉接触控制、排产、换产清洁验证、may contain 咨询声明三选一，以及 Part 117〔§ 117.135(c)(2)〕把「标签控制」作为预防控制来管理的义务；Big 9 类别、Table 1 树坚果封闭清单、allergen-free 与 advisory 声明互斥来自 **FDA Ed.5 guidance（2025-01）**，法源是 FD&C Act §201(qq)/§403(w)，**不属 Part 101、不得标成〔§ 101.xxx〕**。本卡 V01 只给配料表〔§ 101.4〕、显著性〔§ 101.15〕、V03 只给 gluten-free〔§ 101.91〕与亚硫酸盐〔§ 101.100(a)(4)〕的法条层内容义务。两套法源**互不减免**：标签口径收窄不减少厂内预防控制，厂内控制到位也不免除标签义务。
- **CAP-26 `juice-haccp`（21 CFR Part 120）与 CAP-27 `juice-inspection-program`（CP 7303.847）**：管果汁 HACCP 危害分析、〔§ 120.24〕**5-log 持续削减**法定工艺要求、SSOP、记录与检查员取证。本卡 V04 只给〔§ 101.17(g)〕未巴氏果汁 WARNING 声明、〔§ 101.30〕果汁百分比声明与〔§ 101.8〕自动售货机卡路里。**贴了警示不等于做过 5-log；做了 5-log 只是让 (g) 警示不适用，不自动免除 §101.30 等其他标签义务**；CP 7303.847 是检查员作业层，不创设企业义务。
- **CAP-09 `regulatory-boundaries`（双法规与豁免边界）**：管 Part 117 的 qualified facility、LACF/酸化食品、USDA 管辖等**主体/活动豁免**与义务并集。本卡 V05 的〔§ 101.100〕/〔§ 101.9(j)〕/〔§ 101.108〕是**标签义务豁免**，免的是某一条法定信息要求，不是整个主体脱离监管；两者是不同制度，不得互相套用或累加。
- **CAP-14 `cgmp-compliance-guide`（cGMP 合规分诊）**：管 FDA 指南 should/recommend 对企业是否必须做、资料四层效力栈。本卡 V05 的效力层是**法规正文之间的编号并列**（七套编号）与法规＞指南＞检查程序的位阶，约束对象是条款引用，不是指南措辞判读；两者来源不同，不可因「should 怎么读」混引。
- **CAP-15 `defect-action-levels`（缺陷行动水平）**：给 402(a)(3) 掺假裁量阈值出处。本卡的 misbranding 是 **403 错标**轨道；缺陷阈值不是标签合规结论，亚硫酸盐 10 ppm 也不是缺陷行动水平。
- **CAP-29 `iom-imports-procedure`（IOM 2026 Ch.6）**：给进口扣留/改标重整的 **FDA 内部作业链**（Form FDA 766、DWPE、Refusal）。错标的**实体判定依据**部分回到 Part 101，但 IOM 不创设企业义务、其 `must/shall` 约束 FDA 内部作业；不得把 IOM 的时限或文书写成企业的标签义务。
- **CAP-01…CAP-28 其余 PCHF 卡**：危害分析、预防控制管理组件、记录保存、召回、供应链验证等均为**生产过程义务**。本卡不产出 FSP、不设预防控制、不判危害；用户问「标签都合规了是不是就不用做危害分析」时须明确否定并转 `hazard-analysis-method` CAP-01。

## 边界与判停（B 段汇总）

**反场景（不要用本卡 / 不要加载子卡）**
- 用户要**个案合规结论、法定身份判定、标签文书代写或执法结果预测** → 本卡不代写标签/请愿书、不出合规结论、不判产品法定身份、不预测 FDA 执法；回条文与专业审校。
- 用户问的是**过敏原厂内控制、Contains 声明物种范围、may contain 咨询声明** → 转 CAP-05 + Ed.5 guidance 层。
- 用户问的是 **FSP / 危害分析 / 预防控制 / 记录保存 / 召回 / FSVP 主体判定** → 转对应 PCHF 卡；标签合规不替代危害分析。
- 用户问的是**果汁 5-log 工艺设计、HACCP 计划、杀菌验证** → 转 CAP-26；**检查员取样/PAC** → 转 CAP-27 / CAP-17 / CAP-28。
- 把 V05（口径/效力层）当「第 6 张业务卡」独立路由 → 错误；须依附 V01–V04 业务卡使用。

**来源与位阶边界**
- **eCFR 快照，非 GPO 正式文本**：本文自述 `authoritative but unofficial`；2026-11-05 是快照日期而非修订生效日。RACC、DV、声称阈值属持续修订对象，引用具体数值须回 eCFR 当前版与条文末尾 FR citation 复核；不得与 4-1-25 Edition 年度编纂版混称。
- **不可逐字引用区**：§101.12 Table 1 / Table 2（约 113 页，文本层为流式列值、表头脚注逐页重复、列可能错列）；Appendix B 图形增强、Appendix C 生鲜果蔬与 Appendix D 熟鱼 Nutrition Facts 图形；9 个纯图形页（44 / 45 / 51 / 239 / 240 / 344 / 347 / 348 / 351）。只可引「产品类别 → RACC → label statement」对应关系，数值与版式一律回原表核对。
- **转引未收**：FD&C Act 全文（§201(n)/§403 系列）、21 CFR part 1 subpart L、part 102 通用名、part 130 标准身份、part 105 / §105.66、§104.20 强化政策、1 CFR part 51 并入材料、AOAC / 检测方法正文、请愿表格栏目、Form FDA 相关表单、营养数据库与消费调查原始文献、FALCPA 法定过敏原定义本体（在 §201(qq)/§403(w)）。涉及这些法源一律标「转引未收」，不得据本 part 反推其内容。
- **监管者视角与合规成本**：全篇写「标签上必须有什么、话只能怎么说」，默认企业有定量检测、营养数据库、法规事务与标签审核能力；对小微企业只给 §101.9(j) 类豁免，未给出低成本取得可靠营养数据的方法。它不处理「标签正确但产品被污染」或「标签错误但产品安全」的风险分配——后者要靠 Part 117 / 402 掺假条款另行解决。
- **最强反对意见必须保留**：把海量合规成本压在排版、字号、份量换算与逐词声称审查上，而真正造成健康危害的往往是生产过程失控。若不做严格的效力层与接口标注，把 Part 101 并入以危害分析为核心的技能包，反而会诱导使用者把「标签合规」误当「安全合规」——**这是本卡与 5 张子卡 B 段共同的红线**。
- **二十二类不可混引**：七套法规编号〔§ 101 / 108 / 113 / 114 / 117 / 120 / 123.xxx〕并列；FDA 指南（PCHF 指南、L.mono 草案、SECG、Ed.5、Handbook）为 should 建议层；CPGM / CP / IOM 为检查员视角、不创设企业义务。冲突时法规正文为准，指南只作解释与例证。
